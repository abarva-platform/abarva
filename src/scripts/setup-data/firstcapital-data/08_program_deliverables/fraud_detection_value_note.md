# Fraud Detection Enhancement · Value Tracking Note

The Fraud Detection Enhancement program is on track. The committed first-phase outcome is to reduce annualized card fraud losses from $2.1M to $1.2M by June 2026.

Current Q1 2026 run-rate is $1.8M annualized after deployment of high-confidence velocity rules, merchant-category risk scoring, and real-time card velocity monitoring.

Key insight: the fraud program can produce near-term savings without waiting for full core modernization, but expansion into FedNow or RTP fraud monitoring depends on the real-time payments/API layer.

Recommended next gate: decide whether to expand fraud ML to real-time payment flows as part of the FedNow implementation plan, with CRO model-risk approval explicit before scale.
