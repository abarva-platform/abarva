# Tower template — field guide

One row per column across all 45 files in the pack — 791 fields. For each: who in your organisation owns it, which system it comes out of, how to extract it, and what a good value looks like.

## How to use this

Each file is owned by a different team. Send each one to the owner named in the **Owner** column rather than asking a single person to complete the pack — no one person can produce all of it, and a pack filled by one person guessing is worse than a partial pack filled by the people who know.

**A blank is a legitimate answer.** Blanks are reported as coverage gaps. Invented values are reported as fact, and they will be wrong on a board slide.

### Reading `exemplar_status`

| Status        | Meaning                                                          |
| ------------- | ---------------------------------------------------------------- |
| `good`        | Our reference pack demonstrates this field well — copy its shape |
| `thin`        | Only one tenant populates it                                     |
| `not_loaded`  | Present but every value is the literal `not_loaded`              |
| `filler_ramp` | Values form an arithmetic sequence — generated, not real         |
| `uniform`     | Numeric column with almost no variance                           |
| `copy_paste`  | Identical values across two or more tenants                      |
| `missing`     | No tenant populates it at all                                    |

Across the pack: **good** 744, **thin** 44, **uniform** 2, **missing** 1.
