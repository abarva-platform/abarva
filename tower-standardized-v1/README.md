File-only reversible output generated from the five canonical v4 tenant packs. Originals remain untouched.

## What to review first

1. TEMPLATE_SCHEMA.md
2. METADATA_DICTIONARY.md
3. RECONCILIATION_REPORT.md and RECONCILIATION_REPORT.csv
4. SYNTHETIC_MANIFEST.csv
5. Each tenant's derived/tower_financial_amounts.csv

## Scope

This standardizes Tower source files and adjacent IT/finance/source files needed to rebuild Tower. It does not load Azure, alter ACA, deploy, or delete anything.
