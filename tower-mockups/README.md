# Tower Mockups

Static review-only HTML mockups for the Tower surface. There is no build step, no API usage, and no interactivity beyond basic browser scrolling.

Files:
- `landing.html` — role-gated Tower landing showing the CIO default versus the Maestro operating path.
- `dashboard.html` — desktop Tower landing for Apex Retail Group with the 7-zone layout from Packet 5/6, five pillar cards, active signals, pipeline glance, cohort position, and Atlas right rail.
- `maestro-dashboard.html` — denser desktop dashboard variant for a Maestro covering Apex, with approvals, program health, and operational follow-through.
- `pipeline.html` — 9-column Tower pipeline Kanban showing Apex use cases across backlog, active program phases, steady state, and sunset.
- `use-cases.html` — Tower use-case directory with saved views, filter rail, bulk actions, and a power-user table layout.
- `use-case-detail.html` — steady-state living-record page for Contact Center AI Transformation with deeper ownership, regulatory, document, and Atlas context sections.
- `signals.html` — full signals management surface with severity, owners, signal age, status, and action routing.
- `signal-detail.html` — desktop signal-detail side panel for the critical Shadow AI signal, shown open over a muted dashboard background.
- `signal-detail-page.html` — full-page desktop signal detail for deeper evidence, activity, and decision framing.
- `data-integrations.html` — Data & Integrations sub-surface, Integrations tab.
- `data-uploads.html` — Data & Integrations sub-surface, Uploads tab with the 6-step flow visible.
- `data-templates.html` — Data & Integrations sub-surface, Templates tab with CSV template catalog.
- `data-quality.html` — Data & Integrations sub-surface, Data Quality tab with stale data and integration issues.
- `settings-client.html` — Settings page for client configuration, thresholds, and policy defaults.
- `settings-users.html` — Settings page for users, roles, attestations, and access boundaries.
- `settings-cohort.html` — Settings page for cohort peer selection and benchmark transparency.
- `patterns.html` — Genome patterns page showing matched pattern families and applicability to Apex.
- `atlas-chat.html` — Atlas full-screen desktop chat expansion with scripted and routed question patterns.
- `mobile.html` — dedicated 375px mobile CXO view from Packet 7 with Atlas-first summary, horizontal signals carousel, pillar tiles, and Atlas bottom dock.

How to view:
1. Open any file directly in a browser.
2. Example: `file:///Users/anand/Projects/nexus/tower-mockups/dashboard.html`

Notes:
- All data is hardcoded inline from the Tower design packets, the reconciled Apex seed, and the existing Apex program seed where the reconciled spec deferred exact program names.
- These are intended as design review artifacts before real Tower implementation.
