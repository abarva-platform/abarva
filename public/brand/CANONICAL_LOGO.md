# AbarVa Canonical Logo Assets

The canonical AbarVa logo system is **Option 2 — Intersecting A + V**.

Canonical application assets:

- `public/brand/abarva-option2-hq-logo-assets/`

Stable application paths:

- `/brand/abarva-option2-hq-logo-assets/abarva-option2-hq-nav-light-compact.svg` — light-surface compact navbar wordmark.
- `/brand/abarva-option2-hq-logo-assets/abarva-option2-hq-nav-dark-compact.svg` — dark-surface compact navbar wordmark.
- `/brand/abarva-option2-hq-logo-assets/abarva-option2-hq-nav-light-standard.svg` — standard light-surface lockup.
- `/brand/abarva-option2-hq/abarva-option2-hq-symbol-light.svg` — standalone symbol for light surfaces.
- `/brand/abarva-option2-hq/abarva-option2-hq-symbol-dark.svg` — standalone symbol for dark surfaces.

Browser and device icons are generated from the Option 2 app icon assets in `public/brand/abarva-option2-hq/`.

The old root-level aliases, standalone wordmark, monogram, `/logo.svg`, and `/logo-mark.svg` assets were retired so active UI cannot drift back to the previous logo family.
