# Azure Environment Cadence

Status: scaffold-ready

This cadence covers AbarVa product/control-plane environments and client private data-plane environments without confusing the two.

## Weekly Review

- Product Dev changes and hygiene
- Product Preview release-candidate readiness
- Product Prod stability and rollback posture
- Client Preprod rehearsals
- Client Prod incidents, drift, and evidence
- open approval gates
- cost and budget alerts
- security and policy drift

## Monthly Governance Review

- RBAC review
- Azure Policy review
- budget and forecast review
- diagnostic/log retention review
- client private-plane evidence review
- incident/problem review
- context governance and agent-ready promotion review

## Review Outputs

Each review produces a short report with owner, date, findings, decisions, blocked approvals, and next actions. No Azure mutation is implied by this cadence.
