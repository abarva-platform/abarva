## THE NARRATIVE PRINCIPLE — SAME AS THE PRODUCT

Every demo step must answer three questions for the CXO watching:
1. Why does this matter to me right now?
2. What am I seeing that I didn't know before?
3. What would I do differently because of this?

If a demo moment doesn't answer all three — cut it.
The demo is not a feature tour. It is a decision accelerator.

**What Claude Code builds:**

**This is not a demo — it is a negotiation.**
**The product has done its job. Now close.**

we agree on the baseline now, so the attribution is clean later.

No commitment beyond the annual license until you've seen the
intelligence for yourself.

That's the design partner arrangement. What would need to be true
