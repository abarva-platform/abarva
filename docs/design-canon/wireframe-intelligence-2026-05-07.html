What this design is. The visual concretion of the design intent. Three states (empty / partial / mature), one IA (header → attention → top synthesis → pattern queue → "what we can't yet see"), one central affordance (Shape into a Move), zero chat input, zero telemetry console, zero configuration affordances.

What this design is not. Not a dashboard, not a chat surface, not a reasoning console, not a 23-segment landscape, not Tower, not a duplicate portfolio view. (§2 boundaries enforced visually.)

Tenant in mockup. First Capital Financial — used because the design intent doc has worked examples there. Real tenants in app: Apex Retail, Meridian Health, First Capital Financial, Keystone Energy. (Any "Arcturus" reference is a naming reconciliation pending — see substrate readiness check.)

Open before implementation. Substrate readiness — segments 16 (Stakeholder Notes), 18 (Financial Model), 20 (Scenario Library) currently 0% across all tenants; segments 15–23 cannot be inserted into the canonical substrate today (CHECK constraint family_number BETWEEN 1 AND 14). See implementation prompt §0 for the prerequisite work.
