# Corpus Pattern Dossier Spec

## Role

The corpus pattern dossier gives Intelligence precedent and comparison. It should not be treated as tenant proof.

## Selection

The dossier uses already retrieved Intelligence sources and keeps only relevant pattern, worldview, research, regulation, and benchmark material. It selects a compact set for the question budget and records lower-ranked exclusions.

Ranking should continue to improve around:

- industry fit
- function fit
- value lever
- decision intent
- tenant evidence overlap
- maturity stage
- execution risk

## Shape

Each included pattern family carries:

- pattern family id/name
- relevance reason
- industry fit
- function fit
- value lever
- included patterns
- prerequisites
- risks
- evidence strength
- citations

## Guardrail

The prompt composer states: corpus patterns are precedent/comparison, not tenant fact.
