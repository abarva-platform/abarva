# SkyHarbor AMS — Deliverable Intelligence Orchestrator live proof (2026-06-10)

A real, board-grade RFP package generated by the orchestrator's six-pass flow on
**`claude-opus-4-8`**, grounded in **governed evidence read live from the private
data plane** (tenant `skyharbor-air`), executed on Azure Container Apps inside the VNet
(the audited egress preflight needs `ANTHROPIC_API_KEY` + the tenant policy + audit sink,
none reachable from localhost). The generated document was then run through the **real**
`renderers.ts` and `quality-validator.ts`.

## Run

- Where: ACA job on the web image (`abarva/web`) inside the lab VNet; `DATABASE_URL` +
  `ANTHROPIC_API_KEY` from the web app's Key Vault-backed secrets (injected for the run,
  removed on restore).
- Governed evidence: 7 `agent_ready` families pulled live — application inventory, service
  tower scope, SLA baseline, run-cost baseline, staffing baseline, incident/problem/change,
  ticket volumes. **`contract_baseline` (incumbent spend) was excluded from the bidder-facing
  evidence** — the no-incumbent-spend-leak rule, enforced at evidence assembly.
- Prompts: the faithful six-pass sequence (system + context + per-pass instruction) ported
  verbatim from `prompt-builder.ts`.

## What the model produced (quality)

The model self-organized the artifact into:

- **Part A — Steering-committee decision memo** (internal; the *why*, deal shape, money, the
  decision ask),
- **Part B — bidder-facing RFP** (the part the committee authorizes for issue), and
- **Part C — internal annexes** (negotiation levers, risk register, conditions precedent;
  removed before issuance).

This is exactly the disclose-vs-withhold tiering an enterprise sourcing team applies — produced
by expert judgment, not a template.

## Honest scope notes

- The proof script calls the Anthropic SDK directly (the audited-egress wrapper is TypeScript
  with `@/` aliases that don't load in a raw container script). The **audited egress path is
  unit-proven separately** (PR-3 mocked-egress test: every pass routed with a pass-specific
  workflow tag + token budget). Production generation uses that audited path.
- Persistence into `generated_artifacts` was not exercised in this run (it needs the data plane
  from a compiled context); the persistence adapter is unit-proven (PR-5 test) and refuses
  gate-blocked results.
