4 · How this makes Sentinel shine

Sentinel answers like a senior advisor because it fuses two evidence classes the model could never invent: this client's facts (context) and industry/expert patterns (corpus) — every claim mapped to a citation, every gap stated honestly, zero cross-tenant bleed.

Wireflow — question → grounded, cited answer

1
Resolve tenant from session → tenant_id + canonical key (RLS fence).
2
Route segments from intent → e.g. "critical apps + renewals" → cmdb_applications_services, renewal_calendar, vendors_contract_inventory.
3
Retrieve CONTEXT — tenant facts/chunks (search_indexed, tenant_key-filtered).
4
Retrieve CORPUS — matching industry/expert patterns (cross-tenant worldview).
5
Assemble ContextBundle (8 categories) + grounding report; exclude stale / wrong-tenant.
6
Synthesize (Anthropic) on the governed bundle only → claims mapped to sources, missing evidence flagged.

Proven live (job uo8edvw): grounded on each client's own facts, 0 cross-tenant leakage, honest coverage gaps.

5 · How this makes Nexus shine

Nexus turns an AI ambition into a board-grade Move because the same substrate supplies both halves of a strategy: the client's real current state (context) and the expert playbook for the archetype (corpus) — so charters, roadmaps and deliverables are grounded, not generic templates.

Wireflow — ambition → grounded Move

1
Originate a Move → resolve archetype (e.g. "merchandising AI", "prior-auth automation").
2
Evidence requirements per phase (P0→P5) resolved from the archetype.
3
Current-state from CONTEXT — applications, spend, org, KPIs, risks, initiatives (real facts).
4
Playbook from CORPUS — sector playbooks (D17), portfolio-ops (D07), capital allocation (D01), anti-patterns.
5
Promotion-only evidence — only agent_ready facts enter the bundle (11,545 promoted).
6
Generate deliverables — charter · solution architecture · roadmap · value case, each cited; gaps shown.

Substrate ready: current-state facts span all 15 dimensions Nexus needs (apps, spend, vendors, KPIs, risks, initiatives).

6 · Why this substrate is trustworthy — and what it unlocks

Governance & integrity (live-verified)

  • 0 duplicate-active facts · 0 orphans · 0 null-lifecycle across all tenants.
  • Tenant isolation: every retrieval tenant_key-filtered; bundle proof showed 0 cross-tenant leakage.
  • Promotion gate: 11,545 objects agent_ready with 0 gate violations — each has source_basis, confidence, cited-render-verified, indexed, tenant-scoped.
  • Corpus never carries client facts — the two planes are kept separate by contract.
  • Embeddings: 100% real text-embedding-3-small (1536-d), one consistent vector space.

What "good data" buys the agents

  • Specificity: named systems, dollar figures, renewal dates — not generic advice (Epic $13M; Sterling-OMS $7.7M).
  • Defensibility: every claim → a citation a CXO can audit; every gap stated, never invented.
  • Cross-leverage: corpus patterns let Sentinel/Nexus reason about a client they've "never seen" using 9,026 expert patterns + 43,436 genome patterns.
  • Scale path: the same pipeline (load → index → promote → bundle-prove) extends to any new tenant or dimension with zero bespoke code.
  • Module reach: Intelligence proven; Source (vendor/renewal/spend facts), Tower (KPI/risk facts), Moves (current-state + initiatives) are data-ready on the same substrate.
