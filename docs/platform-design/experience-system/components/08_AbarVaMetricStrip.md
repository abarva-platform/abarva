# AbarVa Metric Strip

## Purpose

Show a small set of decision-relevant metrics.

## When to Use

Use near the top of portfolio dashboards and workbench summaries.

## When Not to Use

Do not use for vanity metrics or charts without action.

## Visual Rules

- 3 to 5 metrics preferred.
- Label and value must be clear.
- Secondary explanation is short.
- Warm light cards by default.

## Conceptual Props

- `metrics`
- `label`
- `value`
- `detail`
- `tone`

## Interaction Behavior

Metric can link to filtered table or drawer.

## States

Normal, at-risk, loading, unavailable.

## Accessibility

Numbers should have accessible labels and units.

## Examples

- Active events.
- At-risk programs.
- Value at stake.
- Evidence-ready datasets.

## Anti-patterns

Too many metrics, giant numbers without meaning, chart clutter.

## Acceptance Criteria

Metrics support the page's primary decision.
