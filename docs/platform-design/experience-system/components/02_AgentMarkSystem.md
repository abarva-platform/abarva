# Agent Mark System

## Purpose

Define small marks for Nexus, Sentinel, Atlas, and Steward.

## When to Use

Use in agent panels, briefs, rails, readiness matrices, and context-used strips.

## When Not to Use

Do not use as avatars, mascots, large illustrations, or decorative repeated icons.

## Visual Rules

- Simple geometric marks.
- Work at 16px, 24px, and 32px.
- Secondary to text.
- No excessive color.

## Conceptual Props

- `agent`: nexus, sentinel, atlas, steward.
- `size`: 16, 24, 32.
- `tone`: light, dark, muted.

## Interaction Behavior

Hover or focus may show agent role tooltip.

## States

Ready, partial, blocked, muted.

## Accessibility

Always pair with agent name or accessible label.

## Examples

- Nexus: path/connector.
- Sentinel: signal/evidence.
- Atlas: compass/portfolio.
- Steward: governance/control.

## Anti-patterns

Character art, emoji-like marks, glowing AI icons, Sanskrit symbols.

## Acceptance Criteria

Mark helps identify the agent without becoming the page hero.
