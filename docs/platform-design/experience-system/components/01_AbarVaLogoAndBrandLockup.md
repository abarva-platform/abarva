# AbarVa Logo and Brand Lockup

## Purpose

Provide a trusted, quiet brand anchor for navigation, decks, favicon/app icon, and system surfaces.

## When to Use

Use in top nav, auth entry, executive decks, exported reports, and app icon contexts.

## When Not to Use

Do not use as page decoration, repeated background motif, or oversized hero art.

## Visual Rules

- Wordmark is `AbarVa`, no gap.
- `Abar` near-black; `Va` dark blue.
- Optional mark is small and secondary.
- Must work on light and dark backgrounds.

## Conceptual Props

- `size`: nav, deck, icon, compact.
- `theme`: light, dark.
- `showMark`: boolean.

## Interaction Behavior

In navigation, click returns to the approved entry surface.

## States

Default, compact, dark background, disabled only when decorative in static export.

## Accessibility

Use text label `AbarVa` where rendered as image or SVG.

## Examples

- Top nav wordmark.
- Favicon/app icon lockup.
- Deck cover lockup.

## Anti-patterns

Large decorative marks, Sanskrit symbols, separated `Abar Va`, animated logo clutter.

## Acceptance Criteria

Recognizable at nav size, restrained, and consistent across surfaces.
