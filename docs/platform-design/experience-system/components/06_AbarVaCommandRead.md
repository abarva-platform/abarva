# AbarVa Command Read

## Purpose

Provide a concise executive read on the current work object or portfolio.

## When to Use

Use at the top of portfolio dashboards, event/program workbenches, and executive briefs.

## When Not to Use

Do not use for decorative hero copy or marketing statements.

## Visual Rules

- Can use dark navy for high-impact moments.
- Keep copy short and specific.
- Include value, risk, owner, stage, or next action when relevant.

## Conceptual Props

- `label`
- `headline`
- `summary`
- `primaryMetric`
- `context`
- `nextAction`

## Interaction Behavior

Primary action opens the most important object or blocker.

## States

Normal, at-risk, blocked, low evidence, empty.

## Accessibility

Heading hierarchy must be valid.

## Examples

- Source portfolio command read.
- Atlas executive portfolio brief.
- Steward setup health summary.

## Anti-patterns

Long paragraph, vague AI language, dark panel repeated many times.

## Acceptance Criteria

User understands the operating read in under three seconds.
