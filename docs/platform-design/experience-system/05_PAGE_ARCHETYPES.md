# Page Archetypes

## 1. Executive Entry / Home

- Purpose: orient executive users to what matters now.
- Primary question: what needs my attention?
- Primary action: open the highest-pressure item.
- Above fold: agent brief, top pressures, portfolio signal.
- Avoid: marketing hero pages and generic dashboard tiles.

## 2. Portfolio Dashboard

- Purpose: scan portfolio health.
- Primary question: where is value, risk, owner, and next action?
- Layout: command read, KPI strip, table-forward portfolio, pressure signals.
- Agent role: summarize pressure and recommend next moves.
- Avoid: card-heavy layouts that hide rows.

## 3. Program/Event Workbench

- Purpose: run one high-stakes work object.
- Primary question: what stage are we in and what must happen next?
- Layout: context strip, journey map, active stage workspace, agent panel.
- Agent role: guide the current stage with evidence.
- Avoid: workflow state hidden in tabs.

## 4. Intelligence Canvas

- Purpose: inspect patterns, signals, and evidence.
- Primary question: what pattern is detected and why should I trust it?
- Layout: Sentinel brief, pattern content, evidence drawer, related signals.

## 5. Control Tower Brief

- Purpose: executive synthesis across the portfolio.
- Primary question: what decisions are required now?
- Layout: Atlas brief, pressure list, value/risk table, executive drilldowns.

## 6. Setup/Admin Control Plane

- Purpose: understand tenant readiness.
- Primary question: what is configured, missing, usable, or blocked?
- Layout: Steward brief, readiness panels, data explorer, governance gaps.

## 7. Artifact Review Workspace

- Purpose: get a deliverable reviewed, approved, locked, or reworked.
- Primary question: is this artifact ready to issue?
- Layout: artifact preview, lifecycle tracker, review comments, approvals, evidence.

## 8. Vendor Evaluation Workspace

- Purpose: compare vendor responses and exceptions.
- Primary question: which vendor is leading and what evidence supports it?
- Layout: scorecard, response completeness, exceptions, pricing, Nexus/Sentinel guidance.

## 9. Value Ledger View

- Purpose: track projected, baselined, measured, and realized value.
- Primary question: is value being captured and evidenced?
- Layout: value journey, ledger table, owners, evidence, reconciliation gaps.
