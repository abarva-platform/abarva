# Responsive and Accessibility Rules

## Responsive Rules

- Desktop-first, but narrow-width safe.
- Tables may become stacked rows only when horizontal scroll would fail usability.
- Journey maps must remain readable.
- Right agent panels collapse to drawer or bottom sheet.
- Large command panels should not dominate mobile.
- First viewport must still answer the primary user question.

## Accessibility Rules

- Maintain color contrast.
- Do not rely on color alone for status.
- Major actions require accessible labels.
- Keyboard focus must be visible.
- Tables need clear headers.
- Drawer open/close behavior must be keyboard reachable.
- Agent suggestions must be readable as buttons or menu items, not only decorative chips.

## Narrow Layout Priorities

1. Page identity.
2. Current stage/status.
3. Agent brief or command read.
4. Next action.
5. Highest-value table rows.
6. Details/drawers.
