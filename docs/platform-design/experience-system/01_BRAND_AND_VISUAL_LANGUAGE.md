# Brand and Visual Language

## Experience Goal

AbarVa should feel elegant, premium, calm, enterprise-grade, Apple-like, and data-forward. The product experience creates the wow. The logo creates trust.

## Core Palette Direction

- Default background: warm off-white or warm ivory.
- Primary text: near-black or charcoal.
- Emphasis: dark navy.
- Accent: restrained blue or teal.
- Optional warmth: muted brown only as subtle supporting warmth.
- Risk: muted amber and muted red, used sparingly.
- Success: green only where a state is genuinely complete or healthy.

## Dark Panel Rule

Dark navy panels are allowed only for:

- High-impact command reads.
- Executive briefs.
- Agent insight summaries.
- Small moments that need contrast and gravity.

Dark panels should not dominate the page. AbarVa is not a full dark-mode product by default.

## Visual Character

- Calm density.
- Boardroom-ready typography.
- Clear hierarchy before decoration.
- Status is text-first with restrained color.
- Tables, journey maps, and agent briefs carry the experience.

## Avoid

- Glowing gradients.
- Heavy icons.
- Excessive green.
- Generic AI sparkle clutter.
- Dashboard filler.
- Dark command-center dominance.
- Decorative logo clutter.
- Temporary symbol deprecation: do not render the prior logo symbol in UI surfaces
  until the final logo asset is provided.
