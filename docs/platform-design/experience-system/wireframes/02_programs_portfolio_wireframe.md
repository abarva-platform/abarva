# Programs Portfolio Wireframe

## Purpose

Show the AI transformation program portfolio as an operating queue.

## Primary User Question

Which programs are active, blocked, at risk, valuable, or ready for the next decision?

## Above the Fold

```text
Top nav
[Nexus portfolio command read]
[KPI strip: active, blocked, at risk, value]
[Program table: program, phase, owner, risk, value, next action]
[Pressure signals: 3 highest program issues]
```

## Journey / Progress Behavior

Rows show compact phase strip: Origination, Charter, Diagnose, Design, Execute, Verify.

## Agent Role

Nexus explains program pressure and next moves. Steward appears for governance gates.

## Table / Card Behavior

Table is primary. Cards are limited to command read, KPIs, and top pressures.

## Drawers

Program row opens phase status, context used, deliverables, blockers, and value ledger summary.

## States

Support active, waiting, blocked, at-risk, low evidence, and complete states.

## Responsive Behavior

Table can horizontally scroll on tablet. On narrow mobile, rows become stacked summaries.

## Acceptance Criteria

- Program phase, owner, value, and next action are visible.
- Nexus guidance is context-specific.
- No card-heavy portfolio wall.
