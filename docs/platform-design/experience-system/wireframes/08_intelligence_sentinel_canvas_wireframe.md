# Intelligence Sentinel Canvas Wireframe

## Purpose

Inspect patterns, evidence, signals, and contradictions.

## Primary User Question

What pattern is detected, what evidence supports it, and where does it apply?

## Above the Fold

```text
Top nav with Intelligence active
[Sentinel brief]
[Pattern/signal table or catalog]
[Evidence confidence and freshness indicators]
[Context-used strip]
```

## Journey / Progress Behavior

Use no large journey map unless a pattern review workflow exists. Use review status chips for pattern governance.

## Agent Role

Sentinel leads. Nexus and Atlas appear only through handoffs.

## Table / Card Behavior

Pattern catalog can use cards, but evidence and signal comparison should be table-forward.

## Drawers

Open evidence details, citations, source documents, contradiction logs, pattern governance status.

## States

Low evidence, stale data, missing source, review pending, approved pattern, archived pattern.

## Acceptance Criteria

- Evidence and confidence are visible.
- Pattern claims are not generic.
- Citations are inspectable.
