# Source Dashboard Wireframe

## Purpose

Show the sourcing portfolio as a premium, table-forward operating queue.

## Primary User Question

What sourcing events need attention, what value is at stake, what is blocked, and what happens next?

## Above the Fold

```text
Top nav with Source active
Warm off-white canvas
[Dark navy Source Command Read: at-risk, waiting/blocked, value under management]
[Compact Executive Pressure Signals]
[KPI strip: active, waiting/blocked, at risk, value at stake]
[Live Sourcing Events table visible above or near fold]
```

## Journey / Progress Behavior

Dashboard rows use compact stage/status labels, not full journey maps.

## Agent Role

Nexus leads the command read and pressure signals. Sentinel appears only for evidence/risk claims.

## Table / Card Behavior

Table is the primary portfolio object. Cards only summarize command read, KPIs, and top pressures.

## Drawers

Event rows open sourcing-event detail or a detail drawer with blocker, owner, value, and next action.

## States

Support no events, active events, waiting, blocked, at-risk, and low-evidence states.

## Responsive Behavior

KPI strip wraps. Table scrolls horizontally before becoming stacked rows.

## Acceptance Criteria

- Warm off-white primary canvas.
- One dark command panel at most.
- Event table appears early.
- Value and next action are easy to scan.
