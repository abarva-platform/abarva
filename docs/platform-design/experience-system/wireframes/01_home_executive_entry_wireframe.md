# Home Executive Entry Wireframe

## Purpose

Give executives a fast, calm read on what matters across AbarVa.

## Primary User Question

What needs attention now, and where should I go first?

## Above the Fold

```text
Top nav
Warm off-white canvas
[Atlas/Nexus command read: 2-3 sentence executive brief]
[Top pressure list: Programs, Source, Intelligence, Admin readiness]
[Portfolio table preview: work object, owner, value, risk, next action]
[Agent action strip: three choices plus custom]
```

## Journey / Progress Behavior

Use compact phase strips only on work-object rows. Do not show a large journey map on home.

## Agent Role

Atlas synthesizes portfolio pressure. Nexus joins when the pressure is workflow-specific.

## Table / Card Behavior

Cards summarize only the top pressures. The main operating list is table-forward.

## Drawers

Rows open a drawer with context used, blockers, evidence, and next action.

## States

Empty: show setup and data requirements. Loading: skeleton brief plus table. Error: explain which portfolio source failed.

## Responsive Behavior

Pressure cards stack above a condensed table. Agent actions collapse into a drawer.

## Acceptance Criteria

- Page answers what matters now within three seconds.
- No marketing hero.
- No generic dashboard feel.
- Next action is visible above the fold.
