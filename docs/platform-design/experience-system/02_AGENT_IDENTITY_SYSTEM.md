# Agent Identity System

## Principle

Agents are expert presences inside the workflow, not mascots. Their marks are small, geometric, and secondary. They help users know who is guiding the work without dominating the page.

## Agents

| Agent | Role | Mark Direction | Primary Surfaces |
| --- | --- | --- | --- |
| Nexus | Orchestration, workflow guidance, pathfinding | Connector/path mark | Programs, Source |
| Sentinel | Evidence, signals, pattern detection | Signal/evidence mark | Intelligence, Source support |
| Atlas | Executive synthesis, portfolio, compass | Compass/portfolio mark | Control Tower |
| Steward | Governance, readiness, control | Shield/control mark | Admin/Setup, gates |

## Mark Rules

- Must work at 16px, 24px, and 32px.
- Must work on light and dark backgrounds.
- Simple geometry only.
- No large avatars.
- No decorative character illustrations.
- No excessive icons.
- No Sanskrit symbols.

## Placement

Agent identity appears in:

- Agent panels.
- Command reads.
- Brief headers.
- Context-used strips.
- Review/gate explanations.
- Readiness matrices.

Agent identity should not be the main visual object on a page.

## AbarVa Logo Usage

- Wordmark: `AbarVa`, no gap between `Abar` and `Va`.
- `Abar` in near-black.
- `Va` in dark blue.
- Mark is small and secondary.
- Must work in top nav, favicon/app icon, decks, and light/dark backgrounds.
