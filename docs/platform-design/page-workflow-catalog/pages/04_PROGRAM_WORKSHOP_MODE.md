# Program Journey / Workshop Mode

## Page / Category Name

Program Journey / Workshop Mode.

## Purpose

Support structured program work through phases, workshops, decisions, evidence review, and Nexus-guided next actions.

## Primary User Question

What phase are we in, what decision are we making, and what context does Nexus use?

## Agent Anchor

Nexus is the primary workshop agent. Sentinel supports risk and contradiction checks. Atlas can summarize operating implications. Steward can flag governance gaps.

## Journey / Workflow State

Program journey state: current phase, completed phases, blockers, approvals, waiting inputs, next workshop step, and deliverable readiness.

## UI Zones

- Journey progress.
- Expandable center canvas.
- Nexus Workshop Mode.
- Supporting right context panel.
- Evidence and decision trail.
- Actions and next steps.

## Data Required

Program, phase, workshop, decision, participants, evidence, deliverables, approvals, risks, and previous Nexus turns.

## Seed Data Today

Seeded program journey, seeded phase content, seeded deliverables, seeded evidence placeholders, and deterministic Nexus workshop prompts.

## Real Data Tomorrow

Persisted program journey state, conversation history, uploaded and parsed evidence, decision records, deliverable versions, and approval events.

## Actions Supported

Advance phase, ask Nexus, record decision, request evidence, assign action, review deliverable, and resolve blocker.

## Missing-Data Behavior

Collapse speculative content, name missing inputs, show confidence, and recommend the next evidence or owner action.

## MVP / V1 / V2 Classification

MVP: phase journey and guided Nexus workshop mode. V1: decision records, approvals, and deliverable review. V2: collaborative simulation and orchestration.

## Dependencies

Program workflow state, Nexus context builder, evidence ledger, deliverable state, approvals, and conversation history.

## Wireframe Required

Yes.

## What Not To Show If Data Is Missing

Do not show final recommendations, complete deliverables, or approval-ready status without evidence and workflow state.
