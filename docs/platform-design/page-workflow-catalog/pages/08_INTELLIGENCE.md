# Intelligence

## Page / Category Name

Intelligence.

## Purpose

Expose patterns, signals, topic context, evidence-backed insights, and cross-tenant learning in a governed way.

## Primary User Question

What pattern or signal matters, what evidence supports it, and where should it change action?

## Agent Anchor

Sentinel anchors pattern and signal interpretation. Nexus can translate insight into program or Source action. Atlas can connect insight to operating impact.

## Journey / Workflow State

Insight state: observed, under review, evidence-linked, promoted, applied to work, stale, contradicted, or archived.

## UI Zones

- Pattern library.
- Signal list.
- Evidence readout.
- Topic context.
- Applied-to-work links.
- Confidence and missing-context notes.

## Data Required

Patterns, signals, topics, evidence references, tenant applicability, confidence, contradiction state, and usage history.

## Seed Data Today

Seeded pattern packs, seeded topics, seeded signals, deterministic evidence placeholders, and static applicability notes.

## Real Data Tomorrow

Pattern registry, vector and graph retrieval, evidence ledger, tenant history, applied-work records, and feedback loop.

## Actions Supported

Browse patterns, inspect evidence, apply to program or Source event, flag contradiction, request context, and open related work.

## Missing-Data Behavior

Show low-confidence or missing-evidence state and avoid asserting tenant-specific applicability.

## MVP / V1 / V2 Classification

MVP: browsable pattern library and evidence-aware readout. V1: graph relationships and applied-work links. V2: learning loop and impact measurement.

## Dependencies

Pattern registry, knowledge fabric, evidence ledger, context builder, feedback loop, and Sentinel contracts.

## Wireframe Required

Yes.

## What Not To Show If Data Is Missing

Do not show tenant-specific recommendations, peer claims, or confidence labels without evidence and applicability context.
