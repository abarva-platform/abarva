# Home / Executive Entry

## Page / Category Name

Home / Executive Entry.

## Purpose

Give executives a trusted entry point into portfolio pressure, active programs, Source events, intelligence signals, and the next decisions that need attention.

## Primary User Question

What needs my attention now, and why should I trust that recommendation?

## Agent Anchor

Nexus anchors the executive brief. Sentinel can surface risk signals. Atlas can expose operating implications. Steward can flag setup or governance gaps.

## Journey / Workflow State

Portfolio-level state: active work, blocked work, waiting approvals, stale evidence, upcoming decisions, and escalations.

## UI Zones

- Executive command read.
- Priority decisions.
- Portfolio table.
- Pressure signals.
- Agent brief.
- Recent evidence and activity.

## Data Required

Tenant, active programs, Source events, approvals, risk signals, stale evidence, owner assignments, due dates, and recent agent activity.

## Seed Data Today

Seeded programs, seeded Source events, seeded pressure signals, seeded evidence placeholders, and deterministic agent briefs.

## Real Data Tomorrow

Program records, Source event records, workflow state, evidence ledger entries, approvals, notifications, user assignments, and live agent runtime summaries.

## Actions Supported

Open a program, open a Source event, review a decision, assign an owner, acknowledge an alert, or ask for a focused brief when context is available.

## Missing-Data Behavior

Show setup gaps, unavailable evidence, and which source of truth is missing. Route the user to Admin/Setup or the relevant work surface.

## MVP / V1 / V2 Classification

MVP: executive brief, portfolio list, pressure signals, and clear missing-data state. V1: cross-agent handoffs and richer approvals. V2: forecasting and optimization.

## Dependencies

Program state, Source event state, evidence ledger, agent brief contracts, and Admin/Setup readiness.

## Wireframe Required

Yes.

## What Not To Show If Data Is Missing

Do not show fake ROI, fake urgency, generic AI insight cards, or decorative charts without source data.
