# Programs

## Page / Category Name

Programs.

## Purpose

Show the portfolio of AI and transformation programs, their phase state, risks, owners, evidence readiness, and Nexus brief.

## Primary User Question

Which programs are moving, blocked, or at risk, and what should happen next?

## Agent Anchor

Nexus anchors program interpretation and next action. Sentinel flags execution and evidence risks. Atlas can summarize portfolio operating pressure.

## Journey / Workflow State

Portfolio program state: intake, phase 0, active phase, blocked, waiting approval, completed, or archived.

## UI Zones

- Program portfolio table.
- Nexus Brief.
- Phase and risk summary.
- Owner and next-action columns.
- Evidence readiness indicators.

## Data Required

Programs, phases, owners, milestones, risks, approvals, evidence readiness, value metrics, and recent decisions.

## Seed Data Today

Seeded program portfolio, seeded phases, seeded risks, seeded owners, and deterministic Nexus brief.

## Real Data Tomorrow

Persisted program records, workflow state, approvals, work items, evidence ledger, value metrics, and agent runtime summaries.

## Actions Supported

Open a program, create a program, review phase state, open Nexus brief, assign owner, resolve blocker, or request missing evidence.

## Missing-Data Behavior

Show placeholder state only as missing setup or missing evidence, with the owner and next action.

## MVP / V1 / V2 Classification

MVP: portfolio table, phase state, and Nexus Brief. V1: approvals and work-item orchestration. V2: capacity planning and portfolio optimization.

## Dependencies

Program records, phase state, owner model, evidence ledger, Nexus contracts, and Admin/Setup readiness.

## Wireframe Required

Yes.

## What Not To Show If Data Is Missing

Do not show fake program health, fake phase completion, fake value, or generic generated recommendations.
