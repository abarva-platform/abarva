# Source / Outsourcing

## Page / Category Name

Source / Outsourcing.

## Purpose

Run sourcing event work with a table-forward event portfolio, journey state, event detail pressure, and deterministic agent context.

## Primary User Question

Which sourcing event needs action, what is blocked, and what evidence supports the next move?

## Agent Anchor

Nexus anchors event guidance. Sentinel flags sourcing risks and commercial traps. Atlas summarizes operating implications. Steward flags setup and governance readiness.

## Journey / Workflow State

Source event state: intake, scope, RFP, vendor response, evaluation, negotiation, award, transition, blocked, waiting inputs, or approval needed.

## UI Zones

- Source journey progress.
- Event portfolio table.
- Selected event detail or pressure panel.
- Compact pressure signals.
- Data readiness.
- Agent brief.

## Data Required

Source events, stage state, owners, vendors, requirements, data readiness, artifacts, scorecard status, value assumptions, and evidence references.

## Seed Data Today

Seeded sourcing events, seeded AMS and Data & AI Modernization examples, seeded readiness states, seeded pattern packs, and deterministic multi-agent briefings.

## Real Data Tomorrow

Persisted Source event records, vendor responses, parsed artifacts, normalized pricing, scorecards, evidence ledger entries, approvals, and audit events.

## Actions Supported

Open event, review stage, request data, inspect pressure, ask Nexus, view readiness, route to artifacts, and prepare evaluation steps.

## Missing-Data Behavior

Show blocked or deferred state, identify missing vendor, pricing, scope, baseline, evidence, or approval data, and route to Admin/Setup or event owner.

## MVP / V1 / V2 Classification

MVP: event portfolio, journey state, readiness state, and deterministic agent brief. V1: artifacts, scorecard, and pricing intelligence. V2: negotiation simulation and workflow orchestration.

## Dependencies

Source event model, Admin/Setup readiness, pattern packs, context builder, workflow validation, evidence ledger, and agent briefing contracts.

## Wireframe Required

Yes.

## What Not To Show If Data Is Missing

Do not show generated RFPs, vendor rankings, scorecards, value ledger claims, or negotiation advice without supporting evidence.
