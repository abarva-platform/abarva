# Vendor Evaluation

## Page / Category Name

Vendor Evaluation.

## Purpose

Compare vendor proposals, pricing, risks, service coverage, assumptions, and scorecard readiness without inventing benchmark data.

## Primary User Question

Which vendor is strongest, what assumptions matter, and what should we negotiate?

## Agent Anchor

Sentinel flags commercial and delivery traps. Nexus explains decision context. Atlas summarizes operating impact. Steward flags governance and evidence gaps.

## Journey / Workflow State

Vendor evaluation state: responses requested, responses uploaded, parsed, normalized, scorecard ready, BAFO ready, negotiation ready, or blocked.

## UI Zones

- Vendor comparison table.
- Pricing normalization.
- Commercial trap signals.
- Scorecard readiness.
- Evidence links.
- Negotiation levers.

## Data Required

Vendor responses, pricing line items, scope coverage, service exclusions, SLA terms, assumptions, scorecard criteria, baseline cost, and evidence links.

## Seed Data Today

Seeded vendor examples, seeded pricing structures, seeded trap patterns, and seeded scorecard placeholders.

## Real Data Tomorrow

Uploaded vendor proposals, parsed pricing tables, normalized commercial model, scorecard results, evidence ledger entries, and negotiation history.

## Actions Supported

Compare vendors, normalize pricing, flag traps, request clarification, prepare BAFO strategy, update scorecard, and route to approval.

## Missing-Data Behavior

Show not-ready state and identify missing proposal, baseline, pricing line, scope assumption, or scorecard criterion.

## MVP / V1 / V2 Classification

MVP: structured comparison and missing-data state. V1: pricing normalization and commercial trap detection. V2: scenario modeling and negotiation simulation.

## Dependencies

Source event state, vendor response parser, pricing model, scorecard model, evidence ledger, and pattern packs.

## Wireframe Required

Yes.

## What Not To Show If Data Is Missing

Do not show winner recommendations, benchmark claims, or negotiation targets without proposal and baseline evidence.
