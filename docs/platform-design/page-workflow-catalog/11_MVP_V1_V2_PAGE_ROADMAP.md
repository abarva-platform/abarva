# MVP / V1 / V2 Page Roadmap

## Purpose

This roadmap classifies page implementation by maturity. It prevents pages from showing advanced UI before the data contract and runtime support exist.

## MVP

MVP pages should show truthful state, seed-to-real mapping, explicit missing data, and deterministic agent guidance where context exists.

MVP includes:

- Home executive brief and portfolio pressure.
- Setup/Admin readiness inventory.
- Programs portfolio and Nexus Brief.
- Program Journey Phase 0 and Overview Mode.
- Source dashboard and event portfolio.
- Basic artifact lifecycle state.
- Intelligence pattern browsing with evidence labels.
- Control Tower pressure overview.
- Data readiness inventory.

## V1

V1 pages add collaboration, approvals, richer evidence review, normalized commercial data, stronger cross-agent handoffs, and runtime-backed context.

V1 includes:

- Program Workshop Mode decision records.
- Source artifacts, reviews, and approvals.
- Vendor evaluation with pricing normalization.
- Scorecard readiness.
- Evidence ledger binding.
- Connector-backed Admin/Setup readiness.
- Cross-agent handoff state.

## V2

V2 pages add optimization, simulation, automation, and advanced orchestration after evidence and governance are proven.

V2 includes:

- Portfolio optimization.
- Negotiation simulation.
- Workflow automation.
- Advanced forecasting.
- Learning loop and feedback impact.
- Scenario planning across programs and operations.

## Rule

Do not move a page from MVP to V1 or V2 unless the underlying data contract, evidence contract, and workflow state are ready.
