# Page Workflow Catalog Review Packet

## Review Scope

Use this packet to review any AbarVa page or workflow against the catalog.

## Required Checks

- Page purpose is clear.
- Primary user question is explicit.
- Agent anchor is named and scoped.
- Journey or workflow state is visible where relevant.
- UI zones match the page contract.
- Data required is listed.
- Seed data today maps to real data tomorrow.
- Missing-data behavior is explicit.
- MVP / V1 / V2 classification is present.
- Dependencies are listed.
- Wireframe requirement is clear.
- The page states what not to show if data is missing.

## Design Checks

- No broad page redesign without page contract and wireframe.
- No generic chat UI.
- No magic insights.
- No unsupported ROI, benchmark, score, or readiness claim.
- No decorative data display without source state.

## Runtime Checks

- UI does not assemble prompts.
- Agent response depends on declared context.
- Evidence-backed claims link to evidence or clearly label missing evidence.
- Workflow state is real, not decorative.

## Approval

A page is ready for implementation only when the relevant page file, data contract, wireframe, and component specs are available or explicitly waived.
