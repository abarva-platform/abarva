# AbarVa — Experience Design Spec (Apple-grade)

**Date:** 2026-05-21
**Status:** design spec — v1.
**Pairs with:** `ABARVA-DOMAIN-FUNCTION-PACK-SPEC.md`,
`ABARVA-INVESTOR-DILIGENCE-MEMO-2026-05-20.md`, `PRACTITIONER-FIT-DESIGN.md`.

> **The one-line intent.** Turn AbarVa from a multi-surface tool you navigate
> into a single, function-aware decision surface that opens already
> understanding your world, leads with the answer, and lets you manipulate
> the decision directly.

---

## 1. The principle — density made effortless, not minimalism

AbarVa cannot be minimal. It is a decision OS for CXOs: evidence, financials,
risk, assumptions, sensitivity. That density *is* the value. So "Apple-grade"
here is **not "make it sparse."** It is **"make the density feel effortless
and inevitable."**

The craft is not removal. It is sequencing, anticipation, and restraint — so
a CXO meets the depth in the order they need it, never all at once.

The diligence memo scored Experience low: "four surfaces, not one console";
"no daily-console feel"; "the agent feels generic." This spec answers all
three with one move — and the Domain Function Pack dataset is what makes it
possible.

## 2. The three moves

### Move 1 — Open already understanding the user's world

Today every surface is a generic, blank decision frame. With Domain Function
Packs, the app can open **function-aware**: a Meridian population-health user
sees a home that already speaks value-based care — the right operating
metrics, the MSSP performance-year cadence, the care-gap archetypes, the
vocabulary — with **zero configuration**.

There is one surface — *your decisions* — and it is function-correct from the
first second. Without the Function Pack this is impossible; with it, it is a
binding lookup.

### Move 2 — Lead with the answer; depth is one deliberate gesture

The board-grade decks already prove this (one slide at a time, answer-first).
Make it the whole-app law: every surface opens with **the answer** — one
line, one number, one recommended action — and the evidence, the model, the
assumptions sit exactly one gesture deeper. Never a dump. Never a
dashboard-of-everything. One confident point of view per screen.

### Move 3 — The model is alive under your finger

The expert kernel is deterministic. So a CXO should be able to **touch an
assumption and watch the business case recompute** — direct manipulation of
the decision, not "fill a form, click Generate." (This move is the *next*
reference surface — see §6 — but the home must be built so it can host it.)

## 3. The measurable bar

An experience is Apple-grade for AbarVa only if it clears all of these. Each
is testable.

| Criterion | The bar |
|---|---|
| **Time-to-answer** | The user sees the recommended decision in under ~5 seconds, with zero navigation. The answer is the first thing rendered. |
| **Zero configuration** | The surface is function-correct — right metrics, right cadence, right vocabulary — without the user setting anything. It is inferred from tenant + role + the bound Function Pack. |
| **Depth gradient** | Every figure traces to its evidence in ≤ 2 gestures. Depth is *revealed*, never *front-loaded*. |
| **One point of view** | Each screen makes one argument. No competing panels, no "everything dashboard." |
| **Honest by construction** | A seed gap is shown as a seed gap, plainly, in the experience itself — the no-fabrication discipline is visible, not buried. Missing data never becomes a confident number. |
| **Calm** | Restrained motion, a disciplined type scale, generous whitespace, the locked palette — elevated, never decorated. |

## 4. The reference surface — the function-aware decision home

v1 proves the bar on ONE surface: the **function-aware decision home** for a
Meridian Health population-health user. It is built as a new route — a
reference surface to judge — not a destructive replace of the shipped `/home`.

It binds the **Population Health / Value-Based Care Function Pack** plus
Meridian's real substrate, and renders, top to bottom:

1. **The one thing** — a single confident headline: the most important
   decision-relevant truth right now, in the function's own language. E.g.
   *"Meridian's MSSP performance year closes in 58 days — care-gap closure is
   the gap between shared savings and a loss."* Generated, never generic;
   honest when the data to assert it is missing.

2. **Decisions that need you** — 2–3 answer-first cards, each: the
   recommended action, the financial/clinical stake, the one piece of
   evidence behind it, one gesture into the full decision. Sorted by what
   actually matters now (the Function Pack knows the VBC cadence).

3. **The function's vitals** — a quiet strip of the VBC operating metrics
   from the Function Pack, but Apple-grade: the 1–3 metrics that are *off* are
   surfaced with their read; the rest are collapsed, one gesture away. Not a
   12-tile dashboard.

4. **Where you are in the cadence** — VBC has a performance-year rhythm; the
   Function Pack carries it. The home shows the user where they are in that
   cycle and what it demands.

Everything is traceable: a number opens its evidence; a decision card opens
its costed case. Seed gaps render honestly inline.

**Hard fails for the reference surface:** it requires configuration to be
correct; it opens with a metric grid instead of an answer; a figure cannot be
traced; it shows a confident number where Meridian has a seed gap; it reads
generic — could be any tenant, any function.

## 5. Scope

- **One reference surface**, one tenant-function (Meridian × population
  health), as a new route. Judge it against §3; then spread the pattern.
- **Locked design system** — the canonical tokens, elevated to this bar; no
  new palette, no decoration.
- Grounded: the Function Pack supplies the frame; Meridian's substrate fills
  it; gaps are shown, never faked.

## 6. Horizon — beyond v1

- **The living Move** (Move 3) — touch an assumption, watch the costed case
  recompute. The next reference surface once the home clears the bar.
- **Roll the pattern across the four surfaces** — Intelligence, Moves,
  Source, Tower each become function-aware, answer-first facets of the one
  decision experience.
- Other functions and the retail vertical follow as their Function Packs
  reach depth.

The discipline: prove the bar on the decision home first. A pattern is only
worth spreading once one surface has earned it.
