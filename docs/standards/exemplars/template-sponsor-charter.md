## Frameworks layered

The template layers TIME, Wardley, and Team Topologies. TIME classifies portfolio action, Wardley locates commoditization pressure, and Team Topologies maps the operating-model implication.

## Numerical benchmarks

Run/Grow/Transform benchmark: 60-70 percent Run, 15-25 percent Grow, 10-20 percent Transform (range, n=40 enterprise IT benchmarks, source: AbarVa corpus P-IT-01). Productivity-to-value leakage benchmark: 30-50 percent of saved hours evaporate without a named queue (range, n=18 transformations, source: P-IT-03).

## Anti-patterns

1. Anti-pattern: ghost productivity. This goes wrong when hours saved are not reassigned to named work.
2. Anti-pattern: tool sprawl. This goes wrong when each team chooses a separate AI SDLC tool.
3. Anti-pattern: baseline theater. This goes wrong when adoption is measured before DORA/SPACE baseline integrity is signed.

## RACI and decision rights

RACI: CTO is the single accountable owner. CFO approves value definition. CISO approves model allowlist. HPeople approves ladder changes. Decision threshold: spend above $500K or attrition risk above 5 percent escalates to CEO.

## Sensitivity analysis

If license cost shifts +/-20%, CFO value threshold moves from $2.0M to $2.4M or $1.6M. If adoption shifts +/-20%, pilot cohort expands only when DORA delta remains above 8 percent. If reallocation capacity shifts +/-20%, scope narrows to Invest apps only.

## Sequenced sub-steps

1. Confirm sponsor RACI (2h) depends on CEO/CFO availability.

3. Build reallocation queue (2h) -> depends on portfolio list.
4. Set quality gate (45m) -> depends on kill criteria.

## Quality gate / done definition

Done definition: all five signatories approve, evidence links resolve, thresholds are numeric, and every claim has range, n, source.

## Maturity model overlay

Current stage 2: fragmented pilots with weak evidence. Next stage 3: governed pilot with signed baseline. Stage 5: quarterly verified reallocation and audit-ready model policy.

## Vertical / regional / persona overlay

Healthcare vertical overlay adds HIPAA retention and clinical-safety review. Financial services adds model-risk review. EU regional overlay adds works-council consultation. CFO persona overlay foregrounds realized value; CISO persona overlay foregrounds leakage and indemnity.
