# 20 COMMERCIAL MODEL

## Purpose

AbarVa Source is part of the broader AbarVa platform, not a standalone seat-only product. Its commercial model should reinforce the product's role as an agent-led enterprise sourcing workbench that protects large decisions, reduces sourcing failure, and ties sourcing events to measurable value.

## Commercial Structure

1. Annual AbarVa platform subscription
2. Per-event AbarVa Source fee based on event size and rigor
3. Optional premium advisory or outcome-linked pricing later

## Proposed Event Fee Slabs

| Slab | Deal Size | Fee | Rigor | Examples |
|---|---:|---:|---|---|
| Light event | Less than $1M | $5K-$10K | light | small staff augmentation, small app enhancement |
| Standard event | $1M-$5M | $10K-$25K | standard | app build, data project, small SI selection |
| Enhanced event | $5M-$25M | $25K-$50K | enhanced | transformation program, data modernization partner selection |
| Strategic event | $25M-$100M | $50K-$100K | strategic | AMS, managed services, large platform implementation |
| Enterprise Strategic event | $100M+ | custom / $100K+ | enterprise strategic | multi-year IT outsourcing, large SI portfolio deal |

## Design Implications Of Pricing

| Commercial Tier | Product Requirements |
|---|---|
| Light | minimal gates, basic Nexus guidance, lightweight artifacts, simple status and next action |
| Standard | defined stage gates, required inputs, artifact readiness, scorecard defaults, basic value tracking |
| Enhanced | stronger evidence requirements, scorecard rationale, material-change handling, value owner, executive-ready summaries |
| Strategic | strict gates, scorecard approval and lock, full audit trail, decision memo, lifecycle alerts, value ledger |
| Enterprise Strategic | enterprise audit posture, executive decision record, transition readiness, compliance review, realized value measurement, optional advisory overlay |

Larger events require:

- stricter gates
- stronger audit trail
- scorecard lock
- executive decision memo
- value ledger
- higher evidence confidence
- clearer approval ownership
- more explicit failure-mode coverage

Smaller events use lighter workflow and fewer gates while preserving minimum defensibility.

## Base Platform Subscription

The annual platform subscription should include:

- Pattern Fabric access
- Source Dashboard
- event creation
- basic workflow tracking
- basic Nexus guidance
- identity, tenant, and platform governance
- shared evidence and audit primitives as available

## Per-Event Source Fee

The per-event fee should include:

- sourcing workflow execution
- pattern-pack activation
- required input tracking
- stage gate enforcement
- artifact generation
- scorecard governance
- value ledger
- agent support
- event-level audit trail

## Premium Future Offers

Optional premium offers may include:

- advisory overlay
- benchmark data
- vendor response parsing
- procurement system integrations
- outcome measurement support
- realized value validation
- enterprise evidence library enrichment
- custom pattern-pack authoring

## Commercial Guardrails

- Do not price Source as a generic seat-only workflow tool.
- Do not imply AI generation alone is the value proposition.
- Do not let smaller-event simplicity weaken enterprise rigor for larger deals.
- Do not claim realized value unless measurement evidence exists.
- Do not overbuild vendor portal capabilities before event-side governance is strong.

## Product Metrics That Support Commercial Value

| Metric | Why It Matters |
|---|---|
| value at stake | ties Source to economic decisions |
| event size | supports fee slab and rigor level |
| gate completion | proves process defensibility |
| missing inputs | shows risk avoided before release |
| scorecard lock status | protects evaluation integrity |
| artifact readiness | shows work product progress |
| delay impact | helps executives intervene |
| realized value | supports renewal and outcome pricing later |

## Acceptance Standard

Commercial model is acceptable only when:

- Source pricing reinforces event size and rigor
- product gates scale with deal value
- value tracking is part of the workflow
- per-event economics are clear
- premium future offers do not distort the foundation build
