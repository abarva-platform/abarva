# 12 VALUE LEDGER MODEL

## Purpose

The Value Ledger connects sourcing work to measurable financial and operational outcomes.

It should track:

- projected value
- realized value
- assumptions
- confidence
- variance
- measurement owner
- evidence

## Projected Value

Fields:

- projected value
- source of value
- assumptions
- confidence
- timing
- measurement method
- measurement owner
- realization milestones

## Realized Value

Fields:

- actual value
- measurement evidence
- variance
- variance category
- variance explanation
- attribution confidence
- measurement quality score

## Variance Categories

- scope variance
- execution variance
- external variance
- measurement variance
- combined variance

## Data & AI Modernization Example Line Items

### Legacy platform migration savings

- source: platform retirement and migration economics
- assumptions: retired platforms, run-rate savings, migration timing
- confidence: medium until baseline validated
- measurement owner: Value Office

### Report rationalization productivity

- source: duplicate reports, manual analytics workload, consumption patterns
- assumptions: retirement rate, analyst hours, adoption
- confidence: low until workload baseline is uploaded
- measurement owner: Client PMO Lead

### Vendor consolidation savings

- source: vendor contract inventory and rationalized provider mix
- assumptions: contract overlap, discounting, retained scope
- confidence: medium
- measurement owner: Procurement Lead

### AI-enabled delivery acceleration

- source: delivery model and backlog acceleration
- assumptions: velocity uplift, automation adoption, delivery constraints
- confidence: low until delivery baseline is validated
- measurement owner: Delivery Transformation Lead

## First Slice Rule

The first Source slice should show projected value only.

Realized value should appear as a placeholder with clear language that measurement has not begun.

## Anti-Patterns

- one large value number with no line items
- realized value shown before measurement starts
- hidden assumptions
- no measurement owner
- no variance taxonomy
