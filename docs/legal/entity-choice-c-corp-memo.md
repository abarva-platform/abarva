# Entity Choice Memo: Delaware C Corporation

Status: founder decision memo
Owner: founder
Backlog task: T135

## Decision

AbarVa should operate as a Delaware C corporation for the first enterprise
pilot and institutional financing path.

## Rationale

| Consideration | Why C Corp fits AbarVa |
| --- | --- |
| Venture financing | Institutional venture investors, SAFE/convertible note templates, option pools, and standard financing documents are built around Delaware C corporations. |
| Enterprise procurement | Large buyers are accustomed to contracting with Delaware C corporations and their counsel can process the entity type quickly. |
| IP ownership | Product, corpus, trade secrets, code, prompts, and marks can be assigned cleanly to the company. |
| Equity incentives | Future employee/advisor/contractor equity can be managed through a standard option plan. |
| Acquisition path | Strategic buyers and later-stage investors expect a standard Delaware C Corp cap table. |
| Tax posture | The company can retain earnings for product development and fundraising without pass-through complexity for investors. |

## Alternatives Considered

| Alternative | Why not the default |
| --- | --- |
| LLC | Useful for services businesses or pass-through tax planning, but less standard for venture-backed SaaS, option pools, and institutional financing. |
| S corporation | Ownership restrictions and investor limitations make it a poor fit for venture financing. |
| Sole proprietorship | Not appropriate for enterprise contracting, IP assignment, liability management, or financing. |
| Public benefit corporation | Possible later if mission alignment becomes a commercial advantage, but unnecessary complexity for the first pilot. |

## Operating Requirements

The C Corp decision is only useful if the follow-through is clean:

- founder IP assignment to AbarVa,
- board/stock consent records,
- 83(b) filing if restricted stock was issued and the deadline applies,
- cap table and option plan discipline,
- corporate bank account,
- insurance appropriate for enterprise pilots,
- contract templates in the company name,
- trade secret policy and confidentiality discipline.

## Founder Note

This memo is not legal or tax advice. It records the product/business rationale
for the entity choice and should be paired with counsel and tax review before
any financing or customer contract that depends on entity status.
