# AI Consequential Action Catalog

Status: pilot audit baseline
Owner: AbarVa platform owner
Last updated: 2026-06-01
Backlog row: T231

This catalog lists code paths where the product mutates state, sends or prepares external-facing artifacts, advances workflow state, records approval/sign-off, uploads data, or commits a business decision. It is an implementation inventory, not a policy exception list. `AGENTS.md`, ADR-0006, and `docs/legal/AI_DECISION_SUPPORT_CONTROLS.md` remain the governing standards.

## Control Legend

- `Covered`: current code has an explicit human role/gate, rationale, attestation, or evidence path.
- `Partial`: current code has tenancy/role checks or provenance, but not the full human decision evidence packet.
- `Gap`: current code path needs an explicit human decision control before it should be treated as pilot complete.
- `Read-only`: no state mutation in the audited path; keep labels/citations visible but no approval gate required.
