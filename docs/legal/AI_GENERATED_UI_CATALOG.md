Some rows are deterministic rather than live LLM output; those are still included because users may reasonably treat them as recommendations or AI-derived guidance.

## Control Legend

- `Yes`: visible control is present in the audited code path.
- `Partial`: related label, evidence, or confidence exists, but not the full pilot standard.
- `No`: no obvious visible control was found in the audited path.
- `N/A`: the element is not a generated/recommendation surface in the audited state.
