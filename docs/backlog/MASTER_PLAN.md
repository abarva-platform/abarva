# AbarVa Master Backlog Plan

## North Star

AbarVa is an agent-centric enterprise AI operating system for transformation execution. It must feel premium and calm, operate on real context/evidence, and guide teams through programs, sourcing, intelligence, control tower, and setup with Nexus, Sentinel, Atlas, and Steward.

## Current strongest product spine

The strongest current spine is Source / Outsourcing:

Dashboard -> Event Canvas -> Scope -> Data Readiness -> RFP Readiness -> Vendor Responses -> Pricing Normalization -> BAFO -> Executive Decision -> Vendor Selection Readiness.

## Immediate priority sequence

1. Brand wordmark alignment and visual QA.
2. Vendor Selection Readiness model/panel/smoke.
3. Production-domain visual QA and demo storyline polish.
4. Program flagship deepening and Source link integration.
5. Evidence/upload/pattern runtime plans before model calls.
6. Model Gateway/tool registry only after deterministic paths are clean.
7. Pilot readiness hardening with live route/persona/security checks.

## What not to rush

- Model calls before context/evidence/tool boundaries are enforced.
- Upload/parsing before evidence ledger/provenance rules are designed.
- Workflow/approval engines before gate/readiness panels are stable.
- Scorecard/value ledger UI before vendor selection readiness is coherent.
- Production-ready claims before live tenant/auth/security/persona validation.

## Definition of credible MVP demo

A credible MVP demo can show:

- AbarVa Experience Gallery with approved wordmark and visual system.
- Apex Retail Program journey with workshop/gate/deliverables/evidence state.
- Apex Retail Source event with scope, data readiness, RFP readiness, vendor response completeness, pricing normalization, BAFO, executive decision, and selection readiness.
- Agent missions and context-used patterns for Nexus, Sentinel, Atlas, Steward.
- Production readiness tracker that honestly shows blockers.
