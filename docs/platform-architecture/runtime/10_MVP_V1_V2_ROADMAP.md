# Runtime MVP / V1 / V2 Roadmap

## MVP

MVP establishes truthful deterministic runtime foundations:

- Product-specific APIs above shared services.
- Context Builder for seeded and persisted work objects.
- Deterministic agent response contracts.
- Explicit missing-context behavior.
- Evidence labels.
- Read-only or deterministic tools.
- No direct model calls from agents or UI.

## V1

V1 adds governed runtime depth:

- Model Gateway in production.
- Ingestion and parsing pipeline.
- Evidence ledger records.
- Connector-backed Admin/Setup readiness.
- Graph and vector retrieval.
- Approval and workflow tool boundaries.
- Cross-agent handoffs.

## V2

V2 adds orchestration and optimization:

- Policy-aware model routing.
- Automated enrichment and freshness monitoring.
- Advanced graph reasoning.
- Scenario planning.
- Negotiation and portfolio simulation.
- Feedback loop from outcomes.

## Gate

Do not move a runtime capability forward unless the lower layer is reliable. UI polish cannot substitute for context, evidence, governance, and workflow state.
