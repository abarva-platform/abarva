## Pricing Rationale

AbarVa should not be sold as an AI seat tool. The value anchor is the decision
portfolio: better AI strategy, sourcing, modernization, value/risk, and
executive operating decisions.

The `$300k` pilot fee is intended to:

- keep the buyer serious,
- fund founder-led onboarding and support,
- justify governed data-load and security readiness work,
- avoid a free-trial posture,
- create a clean path to a production subscription.

The `$950k` year-1 target is intended to position AbarVa as an enterprise
operating layer, not a departmental chatbot or narrow workflow tool.

## Founder-Time Framing

Founder involvement is a commercial asset, not free consulting. In pilot
materials, frame it as:

> The pilot includes founder-led executive shaping, data/context setup,
> value-path design, and weekly decision support. This is included as part of
> the pilot package and is valued at approximately 10% of contract value using
> a `$425/hour` premium founder rate. Additional custom work outside the SOW
> uses the same rate as the change-order anchor.

Do not describe founder time as a discount. It is a packaged value component.

## Discount Discipline

| Situation | Recommended response |
| --- | --- |
| Pilot price pressure | Reduce scope or modules before discounting price. |
| Annual prepay | Offer up to 7.5% when cash timing matters. |
| Multi-year year-1 production | Consider discount only for signed expansion or prepay. |
| Source as wedge | Keep Source as a separately visible line item when procurement/sourcing is the economic buyer. |
| Extra users | Use tiered add-ons, not per-seat negotiation. |

## Add-On Logic

| Add-on | Use when |
| --- | --- |
| Source module | Procurement, vendor, BAFO, renewal, or sourcing event is the wedge. |
| Direct connector | API-led or system-led integration is required beyond governed file/template intake. |
| Private data plane | Customer requires Azure/client-scoped data lane beyond shared SaaS pilot posture. |
| Custom corpus overlay | Client needs domain/customer-specific patterns beyond standard corpus. |
| Premium support | Buyer requires support outside pilot model. |

## What Not To Say

- Do not price by casual seat count.
- Do not imply unlimited founder services are included.
- Do not offer production SLA terms before load/SLO evidence exists.
- Do not say private data plane is included unless the SOW includes it.
- Do not discount the pilot without changing scope.
