4. Download — the integrity check that matters

The download endpoint streamed the artifact from Blob and returned HTTP 200 with content-type application/vnd.openxmlformats-officedocument.wordprocessingml.document and a body of exactly 21,607 bytes — byte-for-byte the size recorded at upload. The earlier signed-URL path (which failed under managed identity) was replaced by a server-side byte stream, so the file is retrievable without depending on user-delegation-key SAS rights, with tenant isolation enforced before any byte is read.
