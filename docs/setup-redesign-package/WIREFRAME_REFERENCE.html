Decluttering math

Current Overview: 7 substantial sections · ~1,200 words · 14×6 matrix + 14-row table + 6 fact cards + 4 prose cards + chat
New Overview: 4 small sections · ~150 words · status / orientation / action queue / activity · chat
Decluttering ratio: ~6× reduction in cognitive load on Overview · content didn't disappear, it moved to the panel that's actually about it

Act 3 upload templates → Data Trust (block 3: "Action queue")
Capability Constellation matrix → Agent Readiness (block 2: matrix as page hero)
Four "what this tenant can reason about" cards → Agent Readiness (block 3: per-agent next-action)
Client Data Landscape full table → Data Trust (block 4: collapsed inventory)
Recent activity (compressed) → Overview (block 4: only real changes, max 5 items)
