## Status

`candidate`

## Plain-English Summary

The seventeenth stale-suite triage draw (P3 item 26) judged twenty test files
that no continuous-integration job ran. Its verdicts were recorded read-only in
#8785 (`docs/architecture/item26-draw17-stale-suite-triage.json`). Eleven were
judged `wire_into_ci`: green, behavioural, reading no repository file, over a
subject neither unreachability registry lists. This change does that wiring and
nothing else.

All eleven files were re-executed one at a time on base `788a99f606` before
wiring: 11 suites and 155 cases, all green. They now run on every pull request
in one new step of the `unit-suites` job, `Run the item 26 draw 17 lib suites`,
which names eleven directories whole: `intelligence/dossiers`,
`intelligence/insight-engine`, `parallel-run`, `pilot-dashboard`, `prompts`,
`runtime`, `semantic2/dossiers`, `source/classifier`,
`source/context-writeback`, `source/delivery-model` and
`source/documentation-standards` (each `src/lib/<dir>/__tests__`).
`jest --listTests` over the eleven patterns resolves exactly the eleven drawn
files, so naming each directory whole selects nothing else today, and a test
file added there later also runs.

Nine rows stay held, by verdict, and are not wired: two `repair` rows that read
deleted legacy dataset roots (they join the draw 16 data-lane decision), two
test-only fixture re-key `update_with_reason_recorded` rows, and five rows
whose subjects are still listed as unreachable (held for T-775).

No product file and no drawn test file is edited.
