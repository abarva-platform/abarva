# Exact reviewed source preparation

## Release ID

`2026-10-12-moves-exact-source-preparation`

## Status

`candidate`

## Plain-English Summary

Prepare a bounded source cohort from declared current reviews and original Blob
bytes. A read-only operator plan derives exact Azure index documents and a
prospective index difference. A protected, non-model citation proof checks actual index
membership and content, then renders a literal citation with original-file access.

The default operator entry exposes only planning. The apply adapter refuses execution even when load approval is present. A separately
reviewed serialized writer with actual creation/ownership proof is required.
Prospective missing IDs are not owned and grant no rollback deletion.

## Layer Impact

- Layer 3: reads existing Move, source, review, artifact and readiness records;
  derives index projections of those records. Original source records remain truth.
- Layer 4: a protected read-only citation proof for declared synthetic input tenants.
- Lane: `global-control-lane`, with `client-data-lane` execution separately governed.

## Client Applicability

- All clients: no; the preparation and proof are restricted to declared active synthetic input packets.
- Internal only: operator planning and source verification.
- Public/demo only: declared synthetic input tenants.
- Feature flag: registry-declared synthetic eligibility; no new tenant flag.

Declared active synthetic packets are resolved through canonical code and the
tenant-input registry. Private execution input binds the exact native client, Move,
actor, source IDs, phases, versions and hashes. No tenant list or filename inference.
