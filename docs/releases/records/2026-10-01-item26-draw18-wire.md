## Plain-English Summary

The eighteenth stale-suite triage draw (P3 item 26) judged the last nineteen
test files the coverage ranking held. Its verdicts were recorded read-only in
#8797 (`docs/architecture/item26-draw18-stale-suite-triage.json`), and its one
`repair` row was applied and wired in #8800. Fourteen rows were judged
`wire_into_ci`: green, behavioural, reading no repository file, over a subject
neither unreachability registry lists. This change does that wiring and
nothing else.

All fourteen files were re-executed one at a time on base `b14d9a4856` before
wiring: 14 suites and 353 cases, all green. They now run on every pull request
in two new steps of the `unit-suites` job:

- `Run the item 26 draw 18 lib suites` names thirteen directories whole:
  `source/evidence-trace`, `source/exports/deal-pack`,
  `source/industry-intelligence`, `source/mrm-screen`, `source/should-cost`,
  `source/sourcing`, `source/stage-gate`, `source/stage-packs`,
  `source/taxonomy`, `telemetry`, `workforce-economics` and `workshops` (each
  `src/lib/<dir>/__tests__`), plus `src/scripts/qa/__tests__`. Each holds
  exactly the drawn file; `jest --listTests` over the thirteen patterns
  resolves exactly those thirteen files.
- `Run the item 26 draw 18 new-workspace file` names
  `src/lib/source/new-workspace/stage-plan-snapshot.test.ts` by path with
  `--runTestsByPath`. That directory is already partially covered by name
  elsewhere and holds other files, so naming it whole would widen scope beyond
  the verdict.

Four rows stay held, by verdict, and are not wired: their subjects are still
listed as unreachable (held for T-775).

No product file and no drawn test file is edited.
