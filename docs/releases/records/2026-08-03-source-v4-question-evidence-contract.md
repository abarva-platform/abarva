# 2026-08-03-source-v4-question-evidence-contract - Source v4 Question Evidence Contract

## Release ID

`2026-08-03-source-v4-question-evidence-contract`

## Status

`candidate`

## Plain-English Summary

Adds the Source v4 question/evidence acceptance gate that must pass before a future synthetic
package can enter canary generation, lab load, Cube validation or aVa baseline testing. The gate
defines 150 executive and analyst questions, maps each question to required source domains, files,
columns, planted story records, Cube views, drill members, answer shapes and evidence behavior, and
records a model-fit audit against the current Source Cube layer.

## Layer Impact

- `client-data-lane`: strengthens the offline acceptance contract for a future synthetic Source v4
  dataset; no tenant data is loaded.
- CLIENT INTAKE: no workbook or client-visible intake template changes.
- SOURCE ADAPTERS: adds a verifier for question/evidence coverage before generated rows are
  accepted.
- CANONICAL MODEL: no schema or identity model change.
- PRODUCTS: no UI, Cube runtime, aVa runtime or web product behavior change.

- `docs/source/SKYHARBOR_SOURCE_V4_QUESTION_EVIDENCE_CONTRACT.md` defines the acceptance contract.

  stop conditions.
- `docs/source/skyharbor-v4/source_v4_question_bank.json` contains 150 required questions.
- `docs/source/skyharbor-v4/source_v4_question_coverage_matrix.json` maps questions to files,

- `scripts/source/build-skyharbor-v4-question-evidence-contract.mjs` generates the artifacts.
- `scripts/source/verify-skyharbor-v4-question-coverage.mjs` verifies the generated contract.
- `package.json` adds build and verification commands for this gate.
