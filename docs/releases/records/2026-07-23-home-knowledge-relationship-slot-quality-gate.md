# 2026-07-23-home-knowledge-relationship-slot-quality-gate — Home Relationship Slot Quality Gate

## Release ID

## Status

`candidate`

## Plain-English Summary

The Home Knowledge Pack v3 count-language hardening correctly regenerated Claude-authored relationship reads, but signed-in browser proof showed the Relationships tab could still render an older relationship slot for the `rel` dimension. That left client-visible phrases such as row counts and relationship counts on the page even after the writer passed.

This release fixes the writer merge path so Claude-authored relationship reads always replace the Relationship tab's visible `rel` slot, then validates the final rendered relationship slot before approving a pack.

## Layer Impact

- `global-control-lane`: Home knowledge pack writer behavior changes for every active tenant using the shared Home pack pipeline.
- `client-data-lane`: affected tenant packs must be regenerated through the governed ACA operator job before corrected relationship text is visible live.
- Home content quality gate: the final `design_slots.REL` object is scanned before database approval, so raw data-mechanics language cannot pass through this path.
