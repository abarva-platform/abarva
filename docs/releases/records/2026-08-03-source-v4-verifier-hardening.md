# 2026-08-03-source-v4-verifier-hardening — Source v4 Verifier Hardening

## Release ID

`2026-08-03-source-v4-verifier-hardening`

## Status

`candidate`

## Plain-English Summary

Hardens the Source v4 row-depth verifier so the next synthetic package cannot pass with only a good
first sample of rows. The verifier now validates all rows for required fields, exact dataset
identity, PII patterns, source path consistency, deterministic row hashes, duplicate keys,
time-series coverage, story-thread depth, manifest-declared file grains and cross-file references.

## Layer Impact

- `client-data-lane`: strengthens the offline quality gate for future synthetic Source v4 data; no
  tenant data is loaded.
- CLIENT INTAKE: adds a package manifest contract for source-system file declarations, grains,
  primary keys and references.
- SOURCE ADAPTERS: improves pre-load validation before any generated package can move to an ACA
  operator load.
- CANONICAL MODEL: no schema or identity model change.
- PRODUCTS: no UI or runtime product change.
