## Plain-English Summary

This release changes the signed-in Home experience for the synthetic airline demo from an AI-value command center into a compact Enterprise Landscape briefing. The page now opens with a short executive read, governed metric anchors, visual signals, tabbed views for economics, posture, coherence, trajectory, watchlist, and evidence provenance.

The page does not claim that a fresh deterministic Home evidence packet or Claude synthesis has been generated. Those remain explicit production gates.
