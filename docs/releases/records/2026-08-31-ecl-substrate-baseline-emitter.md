# ECL substrate baseline emitter

## Release ID

`2026-08-31-ecl-substrate-baseline-emitter`

## Status

`candidate`

## Plain-English Summary

Adds a read-only operator script that emits an idempotent SQL baseline for the ECL substrate from
the lab Postgres catalog. The script uses Postgres catalog renderers for constraints, indexes,
functions, views and policies, and only assembles the table column lists itself.

This does not create or apply a migration. It creates the governed mechanism that a follow-up
operator run can use to generate the baseline SQL from the database the product actually reads.
