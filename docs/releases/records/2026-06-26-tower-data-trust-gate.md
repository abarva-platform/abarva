## Plain-English Summary

Adds a reversible Tower data-trust gate that audits the loaded v4 Tower input files for all five canonical tenants before any Tower data reset or reload. The gate reports source-file row counts, join integrity, evidence bridges, vendor deduplication, amount-type classification, portfolio-company gaps, and named missing fields so Tower does not turn thin or mixed-semantics data into confident CIO metrics.

Also fixes the Tower L3 dossier label so non-Lakeshore tenants do not inherit a hardcoded Lakeshore business label.

## Layer Impact

- `global-control-lane`: Adds shared Tower QA/proof tooling and fixes shared dossier labeling.
- `client-data-lane`: Reads tenant-scoped v4 Tower dataset files for audit output only. It does not write or delete client data.
