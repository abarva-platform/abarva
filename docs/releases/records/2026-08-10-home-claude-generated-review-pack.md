## Plain-English Summary

Home now has a review-ready Claude-authored architecture diagram pack for SkyHarbor plus
Claude-generated CXO story blocks and visual specs. The architecture SVGs are generated by Claude,
stored as static assets, validated, and linked to raw Claude responses. The generator now uses
per-diagram streaming calls so large SVG exhibits are not truncated.

## Layer Impact

Layer 4 — Products, `global-control-lane`: updates the stored Home diagram assets and the Home
diagram-pack metadata rendered by the enterprise landscape view.

Approved-content artifact layer: updates SkyHarbor Home approved-content artifacts and review
reports. This does not mutate canonical tenant records, database tables, loaders, adapters, or
runtime data-plane jobs.

## Client Applicability

- All clients: receive the stronger Claude architecture diagram generation and validation tooling.
- Specific clients: SkyHarbor receives generated review artifacts.
- Internal only: raw Claude responses and review reports are for audit/review.
- Public/demo only: none.
- Feature flag: none.
