# Synthetic claims-denial discovery pack

## Release ID

## Status

## Plain-English Summary

Adds an entirely invented discovery pack for a fresh end-to-end Move walk.
Eight documents describe submission cohorts, administrative denial causes,
source ownership, interviews, mature cash dispositions and fictional policies.
The walk notes cover every registered step and distinguish deterministic draft
fill from structured inputs and personal approvals. No real engagement material
is used. No source file is ingested or exposed to a model by this release.
