# 2026-06-12-discovery-plan-charter-hook — Discovery Plan Charter Hook

## Release ID

`2026-06-12-discovery-plan-charter-hook`

## Status

`candidate`

## Plain-English Summary

When a Strategic Move advances from Charter into Discover, the phase-gate route now attempts to generate the Discovery Plan deliverable through the existing Moves orchestrator. The generated artifact is persisted as a normal `generated_artifacts` row with lineage from the governed evidence assembled by the engine. The phase advance remains successful when generation is skipped or blocked; the response reports the generation status so operators can see whether a draft was created, already existed, or needs more evidence.

## Layer Impact

- `global-control-lane`: Adds a Moves lifecycle hook to an existing phase-gate route without changing the route contract or adding a new generic generation endpoint.
- `client-data-lane`: Writes a generated-artifact row only when the existing orchestrator produces a passing Discovery Plan; existing approval and audit writes remain the authoritative gate state.
- `public-demo`: Makes the P1 to P2 walkthrough feel real by creating a Discovery Plan row for Workspace Explorer to surface.

## Client Applicability

- All clients: Phase-gate response includes a non-breaking `discoveryPlanGeneration` status.
- Specific clients: Discovery Plan generation follows the same Moves orchestrator availability and evidence rules as the existing engine path.
- Internal only: No.
- Public/demo only: Useful for pilot/demo Moves walkthroughs.
- Feature flag: Uses existing `moves_orchestrated_deliverables` behavior inside the orchestrator path; no new flag.

## Changes Included

- Adds `autoGenerateDiscoveryPlanOnCharterApproval` lifecycle helper.
- Calls the helper after a successful P1 to P2 phase-gate audit write.
- Persists generated Discovery Plans with source ref `move:{moveId}:discovery_plan`.
- Keeps phase advancement successful when Discovery Plan generation is skipped, blocked, or fails.
- Updates the Moves Workspace adapter to read generated artifacts stored under either tenant UUID or tenant key and dedupe by row id.
- Adds focused tests for helper behavior, phase-gate hook invocation, and existing Moves workspace mapping.

## Rollout Plan

Merge to `main`. No migration is included. The hook runs on the existing phase-gate route after the durable audit log succeeds. Generated Discovery Plan rows appear in Workspace Explorer when the Moves workspace flag is enabled and the tenant has enough governed evidence for the orchestrator to pass.

## Rollback Plan

Revert the PR. Existing generated-artifact rows remain audit evidence and can be ignored by the Workspace Explorer if needed. Disabling the Moves workspace flag hides surfacing without deleting generated rows.
