# 2026-07-23-home-knowledge-v4-empty-response-retry — Home V4 Empty Response Retry

## Release ID

`2026-07-23-home-knowledge-v4-empty-response-retry`

## Status

`candidate`

## Plain-English Summary

Hardens the Home Knowledge V4 candidate generator when Claude returns an empty structured `client_visible` object. The generator now re-asks Claude up to three total attempts with the same authorship contract instead of accepting empty content or filling content itself.

## Layer Impact

- Internal/admin operations: improves governed candidate-generation reliability for ACA operator jobs.
- Client data lane: no content is published by this change. Failed or incomplete generated content remains blocked.

## Client Applicability

- All clients: no direct runtime UI change.
- Specific clients: applies when generating Home V4 candidate review packs for any tenant.
- Internal only: yes.
- Public/demo only: applies to synthetic demo tenant generation jobs.
- Feature flag: none.

## Changes Included

- `scripts/knowledge/build-home-knowledge-v4-review-pack.mjs`
  - adds up to three attempts for empty `client_visible` responses
  - records each empty attempt for audit
  - preserves the rule that Claude authors all client-visible content
