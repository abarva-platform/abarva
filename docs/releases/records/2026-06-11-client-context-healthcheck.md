# 2026-06-11-client-context-healthcheck — Client Context Health Check

## Release ID

`2026-06-11-client-context-healthcheck`

## Status

`candidate`

## Plain-English Summary

Adds a read-only operator health-check harness for the client context layer. It verifies tenant identity, Blob/source-file presence, Postgres context records/facts/chunks, idempotency, Azure AI Search indexing, tenant-scoped retrieval, promotion/readiness status, context-bundle proof, module readiness, and artifact/file-cabinet readiness for the reference clients.

## Layer Impact

- `client-data-lane`: Reads tenant-scoped context metadata, facts, chunks, search documents, and artifact registries from the Azure data plane. It does not mutate rows or promote readiness.
- `internal-admin`: Gives AbarVa operators an evidence-producing report workflow that runs inside ACA/VNet where the private database and search service are reachable.

## Client Applicability

- All clients: No runtime behavior change.
- Specific clients: Health-check baseline covers SkyHarbor Air, Lakeshore Holdings, Apex Retail, and Meridian Health.
- Internal only: Yes, operator evidence generation only.
- Public/demo only: No.
- Feature flag: None.
