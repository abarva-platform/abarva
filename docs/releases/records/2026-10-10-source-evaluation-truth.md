# 2026-10-10-source-evaluation-truth - Evaluation claim safeguards

## Release ID

`2026-10-10-source-evaluation-truth`

## Status

`candidate` - local validation and independent code review completed. Merge, deployment, runtime invariant, and signed-in acceptance are separate proof layers.

## Plain-English Summary

Response evaluation no longer shows an unrecorded Q&A log. Qualitative leverage ratings are labelled as severity, not as evidence of financial impact. Price ranking and commercial scoring are withheld across the entire bid field when recorded pricing is incomplete, uncapped, conditional, invalid, or lacks a cited complete workbook. Withheld scores are excluded from the advisory total rather than displayed as zeros.

The on-screen scorecard and new decision-brief exports use the same recommendation and withholding states. The default weighting model is explicitly distinguished from an approved archetype scorecard. Generic SLA challenge language is independent of client industry.

## Layer Impact

- Release lane: `global-control-lane`.
- Layer 4 products: response-evaluation presentation, advisory calculations, and decision-brief exports consume existing profile evidence with stricter claim boundaries.
- Layers 1-3: no intake, adapter, canonical schema, tenant row, identity, authorization, or RLS changes. No data load or migration.

## Client Applicability

- All clients using Source response evaluation and newly generated evaluation decision briefs receive these safeguards.
- Existing stored artifacts are not rewritten.
- Synthetic demo profiles remain labelled; this release does not turn authored profiles into analysis of uploaded vendor files.
- Feature flag: none added.

## Changes Included

- Reuse the existing BAFO pricing-comparability classifier, with finite cost and cited complete workbook checks.
- Withhold the benchmark, comparative cost posture, commercial contribution, and advancement while the field is not comparable.
- Preserve evidence-free score eligibility despite open challenges; show not-scored states consistently in export tables and rationale.
- Keep current and hypothetical BAFO scores on the same commercial-comparability basis.
- Remove the unrecorded Q&A component and update its layout harness and generated vocabulary inventory.
- Correct severity labels and industry-independent SLA rationale.

## Known Gaps

This is a guard over recorded pricing fields, not a full cross-bid pricing normalizer. The archetype playbook is not wired into evaluation weights or disqualifiers. This release does not certify commercial recommendations, benchmark representativeness, cited source retrieval, or live analysis of real vendor uploads. The existing evaluation layout has mobile overflow. Full playbook integration, vendor-specific sourced negotiation logic, and responsive layout work remain separate slices.
