## Plain-English Summary

This release tightens three Source proof gaps without changing live client data. The Responses stage now sends a smaller parser payload to the route frame, the typed-fact upload path has a regression test proving written facts can hydrate workflow task readiness, and Source aVa has a 50-question hard-QA harness for Optimize Contract, Contract 360, New Event, vendor responses, portfolio figures, and chart/table answers.

## Layer Impact

- Release lane: `global-control-lane`.
- Products: Source event pages receive a lighter route payload for proposal parser reports. Source aVa gains a repeatable audit harness.
- Canonical Model: No schema or stored-data change. The upload test verifies the existing typed-fact write/readback seam.
- Source Adapters: No adapter behavior change. Existing template ingestion is exercised by tests.
- Client Intake: No client-facing template change in this release.

## Client Applicability

- All clients: Source route payload trim, upload readback regression coverage, and aVa hard-QA harness.
- Specific clients: None.
- Internal only: The hard-QA script is an internal audit tool unless run manually against a signed-in or captured response set.
- Public/demo only: None.
- Feature flag: None.

- `src/lib/source/proposal-intelligence/parser.ts` adds route-level compaction for proposal parse reports.
- `src/app/(maestro)/source/events/[eventId]/page.tsx` uses compact parse reports on the Responses stage.
- `src/lib/source/proposal-intelligence/__tests__/proposal-intelligence.test.ts` verifies compaction preserves scoring and value-plan inputs.
- `src/app/api/v1/source/[eventId]/facts/ingest-file/__tests__/route.test.ts` verifies written typed facts hydrate the matching workflow upload task.
- `scripts/audit/source-ava-hard-qa.mjs` adds the Source aVa 50-question hard-QA harness.
- `package.json` adds `npm run audit:source-ava-hard-qa`.
