## Plain-English Summary

This release tightens the Source D24 Evaluation Decision Brief so it reads and exports like a CXO-facing board-pack artifact. It removes stale working event metadata from export headers and filenames, and restructures the decision brief around an executive recommendation, vendor ranking cards, a readable weighted scorecard, BAFO improvement scenarios, and a final decision-required box.

## Layer Impact

- `global-control-lane`: Updates shared Source artifact export behavior and D24 decision-brief content for any Source event that renders the decision brief through the standard routes.
- `public-demo`: Improves the SkyHarbor AMS outsourcing demo board-pack packaging without adding client-specific runtime forks.

## Client Applicability

- All clients: Source export metadata now prefers the rendered payload's event code when the payload intentionally normalizes the public-facing event label.
- Specific clients: SkyHarbor Air demo event benefits from the clean `SKYH-AMS-RFP-2026` label for D24 exports.
- Internal only: None.
- Public/demo only: The visible board-pack copy polish is currently exercised on the Source P1 SkyHarbor demo path.
- Feature flag: None.

## Changes Included

- Added `src/lib/source/exports/metadata.ts` for shared export metadata helpers.
- Updated the unified Source render route and legacy DOCX/PDF/HTML/XLSX routes to use payload-normalized event codes in response metadata where available.
- Updated Source deliverable filenames generated by the dispatcher to use the payload event code instead of the raw source event id.
- Reworked `d24_decision_brief` content generation into a less dense executive board-pack format.
- Added regression coverage for decision-brief board-pack sections and metadata helpers.
