The strategic thesis (thought leadership)

Insight 1 — Don't reinvent; mirror. origin/main just merged the Strategic Move Archetype Framework (#3371) — the exact architecture this brief specifies (StrategicMoveArchetype object + registry + two-axis resolver + methods-as-library + promotion-only evidence ladder + GroundedAnswerEnvelope). It even ships a seed IT_SOURCING_EVENT archetype proving generality. The fastest path to world-class Source is to mirror this proven engine into src/lib/source/archetypes/ — same shape, sourcing-specific evidence families, methods, RFP structures, pricing models, negotiation levers.
Insight 2 — "Same spine, different DNA." Every sourcing event walks the same 14-step spine, but AMS, ERP/SI, AI-platform, and renewal are different organisms: different evidence packs, RFP structures, pricing models, negotiation levers, deliverables. Source today gives them identical DNA. The archetype contract is the DNA.
Insight 3 — A generic RFP fails the CIO test. A leader running a multi-million-dollar AMS or ERP sourcing will reject a generic RFP on sight. Best-in-class means an AMS RFP has service towers, SLAs, ticket bands, retained-org, productivity glide-path; an ERP/SI RFP has process scope, rollout waves, integrations, data migration, cutover, SI staffing. These cannot share one template.
Insight 4 — Ungoverned confidence is a trust-moat breach. RESOLVED Source hardcoded live-evidence confidence to 'high' and never gated by agent_ready — it could present weak or cross-tenant data as certain. Fixed in Phase 6: confidence is now a function of agent-ready evidence coverage, cross-tenant candidates are fenced, and the agent refuses rather than answer from ungoverned context. This is the trust moat made executable.
