## Overview

This document inventories the canvas elements for **P4 Roadmap & Business Case**.

P4 answers: "How do we sequence, fund, measure, govern, and prepare for change?" It produces: an execution roadmap, a business case, a value plan, and (importantly) a Tower metric plan. The doctrine requires that the Tower metric plan be **proactively surfaced at mid-P4**, not just at gate time.

**Gate structure (from `governance.ts` P4→P5 rule):**
- Hard checks (5): `execution_roadmap_drafted`, `business_case_approved`, `execution_milestones_defined`, `execution_success_criteria_defined`, `readiness_and_change_plan_signed_off`
- Soft checks (6): `funding_approval_recorded`, `sponsor_alignment_confirmed`, `delivery_raci_named`, `vendor_selection_approved`, `tower_metric_plan_drafted`, `tower_handoff_plan_accepted`
- Total: 11 checks (5 hard + 6 soft)

Shell elements are documented in `01-anatomy-shell.md`.

## P4.5 Tower metric plan panel

| Field | Value |
|---|---|
| **ID** | `ws-canvas-p4-towermetric-panel` |
| **Element type** | Panel |
| **Parent** | `ws-canvas-p4` |
| **Visibility** | Always when `ws-canvas-p4` is active; **proactively surfaced at mid-P4** |

**Description:** The Tower monitoring metric plan panel. This panel captures the metrics that Tower will track during execution. It is a **soft gate criterion** (`tower_metric_plan_drafted`) but must be **proactively surfaced at mid-P4** by Nexus — not left until gate time. Mid-P4 is defined as when the roadmap and business case panels both have content (i.e., progress > 50%).

This proactive surfacing ensures the Tower metric plan is built alongside the value plan, not as an afterthought.

**Children:**

| Child ID | Type | Description |
|---|---|---|
| `ws-canvas-p4-towermetric-panel-header` | Label | "Tower Monitoring Plan" |
| `ws-canvas-p4-towermetric-panel-content` | Field (editable) | Tower metric plan documentation |
| `ws-canvas-p4-towermetric-panel-status` | Badge | `not-started` / `in-progress` / `complete` |
| `ws-canvas-p4-towermetric-kpi-{n}` | List item | Tower KPI entry (n = 1..N) |
| `ws-canvas-p4-towermetric-kpi-{n}-metric` | Label | KPI name |
| `ws-canvas-p4-towermetric-kpi-{n}-threshold` | Field | Alert threshold |
| `ws-canvas-p4-towermetric-kpi-{n}-cadence` | Field | Measurement cadence |
| `ws-canvas-p4-towermetric-add-kpi-btn` | Button | Add Tower KPI |
| `ws-canvas-p4-towermetric-proactive-prompt` | Banner | Mid-P4 proactive prompt from Nexus: "Time to draft your Tower monitoring plan" |

**Visibility rule for `ws-canvas-p4-towermetric-proactive-prompt`:** Shown when `ws-canvas-p4-roadmap-panel-status` and `ws-canvas-p4-businesscase-panel-status` are both `in-progress` or later AND `ws-canvas-p4-towermetric-panel-status` is `not-started`.

## P4.6 Gate panel

| Field | Value |
|---|---|
| **ID** | `ws-canvas-p4-gate-panel` |
| **Element type** | Panel |
| **Parent** | `ws-canvas-p4` |
| **Visibility** | Always when `ws-canvas-p4` is active |

**Description:** P4→P5 gate criteria panel. 5 hard + 6 soft = 11 total checks (from `governance.ts`).

**Gate items (hard):**
- `ws-canvas-p4-gate-item-1`: Roadmap drafted (hard)
- `ws-canvas-p4-gate-item-2`: Business case approved (hard)
- `ws-canvas-p4-gate-item-3`: Execution milestones defined (hard)
- `ws-canvas-p4-gate-item-4`: Success criteria defined (hard)
- `ws-canvas-p4-gate-item-5`: Change readiness and adoption plan signed off (hard)

**Gate items (soft):**
- `ws-canvas-p4-gate-item-6`: Funding approval recorded (soft)
- `ws-canvas-p4-gate-item-7`: Sponsor alignment confirmed (soft)
- `ws-canvas-p4-gate-item-8`: Delivery RACI named (soft)
- `ws-canvas-p4-gate-item-9`: Vendor selection approved if applicable (soft)
- `ws-canvas-p4-gate-item-10`: Tower metric plan drafted (soft)
- `ws-canvas-p4-gate-item-11`: Tower handoff plan drafted (soft)

**Children:**

| Child ID | Type | Description |
|---|---|---|
| `ws-canvas-p4-gate-item-{1..11}` | List item | Gate criterion |
| `ws-canvas-p4-gate-item-{N}-status` | Icon | Status |
| `ws-canvas-p4-gate-item-{N}-severity` | Badge | Hard / Soft |
| `ws-canvas-p4-gate-item-{N}-description` | Label | Criterion text |
| `ws-canvas-p4-gate-summary` | Label | "X of 11 met (X hard, X soft)" |
| `ws-canvas-p4-gate-promote-btn` | Button | Promote to P5 |
