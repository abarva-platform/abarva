## 3. Gates — do not cross without explicit approval

- Registry activation or any change to declared tenancy
- Replacing an active root
- Azure/Postgres load, retrieval indexing, product or aVa activation
- Tenant data deletion or move
- Changes to the canonical CSV column contract

Mutating data builds run as **ACA Jobs**, per `docs/ops/aca-data-build-job-rule.md` — not through
production web requests, and not as long-running `az containerapp exec` sessions.

## 4. Two rules that have cost the most when broken

1. **Measure the checkout you think you are measuring.** A prior session concluded a layer was still
   broken because it imported a source file from a stale working tree rather than `origin/main`, and
   nearly filed that as another lane's failure.
2. **Validators run across all active tenants; data mutations touch only in-scope tenants.** A
   previous handoff said acceptance was "for every active tenant", which was read as licence to
   mutate all seven. 27 of 40 changed files were out of scope.

## 5. What this lane just finished — context, not your work

Two PRs, both `internal-admin`, no runtime rollout:

- **#6401** (merged, `3121b2da`) — contract packet machinery:
  `contract facts → packet → clause extraction → reconciliation proof`. `npm run packet:check`.
- **#6404** (open) — cover entities for parties in synthetic contract documents. The packages
  contained documents reading as executed agreements with real companies carrying invented
  commercial terms, in a public repo. 113 files re-keyed, 30 renamed, 5 PDFs regenerated, plus a CI
  gate (`npm run validate:no-real-vendor-parties`).

**One thing from #6404 that affects you:** the rule is that a real company **may** appear in an
inventory — recording that a business runs a given productivity suite is a fact about that business
— but **may not** appear as a party to a document that looks executed. Tenant vendor and application
inventories were deliberately left untouched on that basis. If consolidation moves contract
documents around, keep that line intact; the gate will catch violations under
`datasets/source/contract-intelligence/` but does not yet scan tenant input packages.
