# Databricks on AWS lakehouse move brief (synthetic)

Meridian does not have mature cloud data capabilities today. Current analytics depend on Oracle/Teradata marts, Hadoop raw zones, SAS jobs, Tableau extracts, BusinessObjects, and manual reconciliations. The target architecture uses Databricks on AWS, Unity Catalog, FHIR/HL7/EDI ingestion, governed bronze/silver/gold zones, and certified semantic products for patient/member 360, prior auth, call center, HEDIS/STAR, cost-of-care, payment integrity, and close reporting.
