# Tower Outcome Evidence Template Pack v1

Purpose: capture the evidence Tower needs to move beyond portfolio display into value realization, executive decisioning, action follow-through, and outcome verification.

The Intelligence Explorer can answer what is known from context. Tower needs a different layer: baselines, targets, actuals, decision owners, risk/watch items, committed actions, value states, metric provenance, and handoffs from Moves/Source/Intelligence.

These files are templates only, not seed data.

## Minimum Intake Set

1. `01_tower_metric_baselines.template.csv`
2. `02_tower_value_outcome_ledger.template.csv`
3. `03_tower_decision_queue.template.csv`
4. `04_tower_action_commitments.template.csv`
5. `05_tower_risk_watchlist.template.csv`
6. `06_tower_move_handoff_metrics.template.csv`
7. `07_tower_metric_provenance.template.csv`
8. `08_tower_executive_narrative_events.template.csv`

## What This Enables

- Value-at-risk and value-realized views.
- Baseline vs target vs actual tracking.
- Executive decision queue with owner/date/blocker.
- Action queue and overdue commitments.
- Move-to-Tower handoff proof.
- Metric provenance, including whether a number is measured, estimated, attested, disputed, or stale.
- Honest Tower gaps when baselines or actuals are missing.
