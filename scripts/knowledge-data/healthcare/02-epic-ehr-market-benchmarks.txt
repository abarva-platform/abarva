EPIC DATA ARCHITECTURE FOR AI

Epic Chronicles: Operational transactional database (proprietary InterSystems Cache/IRIS)
Epic Clarity: SQL read-only reporting database (daily sync from Chronicles, 2,000+ tables)
Epic Caboodle: Epic's own cloud data warehouse (replacing Clarity for analytics)
Epic Cosmos: De-identified research database — 265M+ patient records from 200+ contributing organizations (largest longitudinal EHR dataset in US healthcare)
FHIR R4 API: Epic App Orchard certified apps (800+ apps) use FHIR R4
Epic-to-Cloud pipeline: Epic → FHIR R4 API or Clarity → Azure Synapse or Snowflake → AI model

Recommended AI pipeline architecture (2025):
- Option A: Epic Clarity (SQL) → Azure Data Factory → Azure Synapse → Azure ML / Azure OpenAI
- Option B: Epic FHIR Bulk Export → AWS HealthLake → SageMaker
- Option C: Epic Caboodle → Databricks (most AI-forward, 2024-2025 emerging standard)

Integration complexity: HIGH — Epic Certified interface developer required ($180-320/hour)
Average full Epic-to-AI pipeline integration cost: $2.4-4.8M including data validation and model training

Annual Epic optimization spend (large IDN): $3.8-6.4M per year
Epic optimization FTE per $1B revenue (recommended): 0.8-1.2 FTE

1. Workflow redesign for AI integration: requires dedicated Epic analyst time; 800-1,600 hours per AI module

EPIC ECOSYSTEM LOCK-IN ANALYSIS

Lock-in factors (reasons health systems do not leave Epic):
1. Patient data migration cost: $8.4-18M one-time migration for large hospital
2. Staff retraining: 2,000+ staff must be trained on new EHR; productivity loss of $12-22M
3. Epic Cosmos access: 265M patient records for AI research lost if leaving Epic
4. App Orchard ecosystem: 800+ certified apps; most do not support non-Epic EHRs
5. Payer integration: Epic has direct connections with 280+ payers; migration requires rebuilding all EDI connections
6. AI investment sunk cost: AI modules built on Epic architecture are not portable

Switching cost estimate (large IDN leaving Epic): $84-180M total (migration + retraining + new implementation)
Health systems that have left Epic (2022-2025): 3 known cases (all small, < 200 beds)
Conclusion: Epic is effectively irreversible for large health systems that have deployed for > 5 years
