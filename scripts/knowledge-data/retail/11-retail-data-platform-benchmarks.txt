RETAIL DATA PLATFORM LANDSCAPE
Snowflake: 41% adoption among $1B+ retailers (strongest in retail)
Databricks: 34% adoption (ML-heavy retailers prefer Databricks)
Azure Synapse: 18%
AWS Redshift: 14%
Google BigQuery: 12%
On-premise DW still primary: 52%

MEDALLION ARCHITECTURE ADOPTION (DATABRICKS)
Retailers with medallion (Bronze/Silver/Gold) architecture: 28%
Key benefit: unified product, customer, and transaction data for AI
Bronze layer: raw ingestion (all sources, no transformation)
Silver layer: cleaned, deduplicated, entity-resolved data
Gold layer: business-ready, AI-ready aggregates
Time to implement medallion architecture: 4-8 months
AI model quality improvement with medallion vs. ad hoc: 44% better features

DATA LATENCY BENCHMARKS
Batch pipeline (nightly): 41% of retail data pipelines
Near-real-time (15-min to 1-hour): 34%
Real-time streaming (< 60 seconds): 18%
Data latency impact on demand sensing: batch misses 14% of signal vs. streaming
Real-time inventory update requirement: BOPIS requires < 5 minute latency
