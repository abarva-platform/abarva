## What would make this PR unsafe to build on, if it happened later (guardrails already in place)

- If a future change made `deriveReadiness()` return `ENABLED_AND_PROVEN` for `availabilityState:
"candidate"` or `"withheld"`, the "never-fabricate invariants" property test in `TEST_PLAN.md` §2
  would fail immediately — this is the single highest-value regression test in the suite and should
  never be weakened or skipped.
- If a future change imported `src/lib/knowledge/providers/**` from inside
  `src/lib/knowledge/view-model/**`, the assembler would silently regain a dependency on the frozen
  duplicate — guarded by the `no-restricted-imports` eslint rule described in
  `VIEW_MODEL_ASSEMBLER_INTERFACES.md` §4.
