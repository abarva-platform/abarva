# Healthcare Synthetic Enterprise Profile

Healthcare Demo New is a fictional large integrated delivery network and health plan with hospitals, ambulatory clinics, employed and affiliated physicians, a Medicare Advantage-heavy covered-life base, pharmacy, population health, claims/member operations, revenue cycle and centralized shared services.

The technology posture is intentionally not cloud-native. Epic anchors clinical and revenue-cycle operations. On-premises SQL Server marts, SSIS, SSAS, SSRS, Oracle, flat-file exchanges and a legacy EDW remain operationally critical. Azure is the current data foundation and supports a few live AI/use-case workloads. Leadership is expected to pivot future agentic and transformational use cases toward AWS, creating a real coexistence and governance problem rather than a simple cloud migration.
