Claude Code Instructions
The Problem
src/app/admin/page.tsx is currently routing to /maestro/meridian.

Both /admin and /maestro/meridian render the same MaestroClientWorkspace component.

They must be DIFFERENT components with DIFFERENT sidebars and DIFFERENT content.
The Fix
1. Create src/app/admin/page.tsx as standalone AdminPortal component

2. AdminPortal uses AdminSidebar (not MaestroSidebar)

3. AdminSidebar sections: Users & Access · Client Governance · Data Governance · Platform

4. Main content: stat cards + Maestros table + Sensitive Data Approvals table

5. Font sizes per spec above — sidebar items 13px, table cells 14px, row padding 12px 16px
⚠ Do not share layout components between /admin and /maestro. They are separate pages. Build AdminPortal from scratch using this spec file as the single source of truth.
